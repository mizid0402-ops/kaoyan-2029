# 端口规格：M29 正方 PDF 导入适配器（④b-2）

> 路线图 ④b 的第二条导入路线（用户 2026-09-30："两条都做，ics 优先，正方 PDF 解析备用"）。状态：**草案，待 sol 审细则**。
> 上级规格：`contracts/timetable_import.md`（暂存格式 §3、`restage` / `apply` §3 / §5、隔离检查 §1 全部沿用；本文件只定义"PDF → 候选学期"）。
> 实现：`ky/timetable_io/zfsoft_pdf.py`；契约测试并入 `tests/contract/test_timetable_io_port.py`。
> 由来：sol 225 R5 指出"按整星期文本流 + 标记计数"不能保证记录边界；决策者 2026-09-30 对一份真实正方 PDF 做了结构探针（结论见 §2，个人内容不入库），
> 并用本文件的规则写了一次性原型：解析出的课程与手工转录**逐门一致**（星期、节次、周次全同，课程名仅空格写法不同）。

## 1. 职责与边界

- 只支持一种**明确的模板** `zfsoft_rotated_v1`（§2）。不是通用 PDF 理解：版式不符即违约"不是可识别的正方课表版式"，不猜测、不部分导入。
- 分两层：**片段层**（`pypdf`，读文件）与**解析层**（纯函数 `parse_zfsoft_fragments(fragments, template) -> 课程列表`，不读文件）。
- 丢弃教师、场地、教学班、学分等字段；只保留课程名、星期、节次、周次。
- 学校档案 `system` 为 `zfsoft` 时，`ky timetable import-pdf` 默认用本模板；其他系统要新增模板或适配器，不改本解析层。

## 2. 模板 `zfsoft_rotated_v1`（探针得到的版式事实）

片段层交给解析层的是冻结对象：`Page(number, width, height, rotate)` 与 `Fragment(page, x, y, font_size, text, index)`。
`x, y` 为 `visitor_text` 的 `cm × tm` 变换后的用户空间坐标；页号从 1 开始；`index` 是片段在该页的提取序号（错误定位用）；
`text` 去首尾空白后非空才收；`text` 含换行 → 违约。坐标与字号必须是有限数。

| 事实 | 取值 / 规则 |
|---|---|
| 页面 | 所有页的 `width`、`height`、`rotate` 与第 1 页相同，否则违约（sol 231 P2） |
| 星期标签 | **只在第 1 页**：恰有 7 个文本分别为 `星期一`…`星期日`、字号 12 的片段，x 相同（误差 ≤ 0.5）、y 严格递增且等距（相邻差与均值偏差 ≤ 均值的 2%）。设标签 x 为 `Lx`、间距为 `S`。**第 2 页起出现任何星期标签 → 违约**（续页重复表头意味着版式不同） |
| 区域（互斥，sol 231 P1） | 第 1 页 `x < Lx − 0.5` 为**页眉区**，其余（第 1 页 `x ≥ Lx − 0.5` 与第 2 页起全部）为**正文区** |
| 锚点 | 取正文区中字号 9 的片段，对每个片段求它与"y 大于它的最近一个标签"的差 `label.y − frag.y`，只收 `0 < 差 < S/2` 的；这些差的最大值与最小值相差 ≤ 1.0，`d` = 二者中点，否则违约（不取众数、不依赖枚举顺序）。锚点ₖ = 标签ₖ.y − d |
| 课程片段 | 正文区、字号 8 或 9、y 与某锚点相差 ≤ 0.5 |
| 其他片段（白名单，按区域） | 页眉区：任意字号与文字，但**不得**是字号 8/9 且落在锚点上（否则违约：无法唯一分类）。正文区：字号 12 且文本恰为 `时间段`、`节次`、`上午`、`下午`、`晚上` 之一或纯数字（节次编号），或第 1 页的 7 个星期标签；字号 8 且以 `: 理论` 或 `打印时间:` 开头；这些都**不得**落在锚点上。**其他任何片段 → 违约**（只报页码、坐标、提取序号与判定阶段，不回显文字） |
| 结构标记覆盖（sol 232 N1） | 不逐片段找完整标记，改为**按字符保守拒绝**：页眉区片段含 `节`、`周`、`学分` 或半角括号 `(` `)` 之一 → 违约；正文区的白名单是精确文字或固定前缀，本来就不含这些字符（`节次` 是精确清单里的整词）。因此课程详情无论被切成几段，只要落进白名单区域就会被拒，不会被静默丢掉 |

## 3. 记录切分与核对（纯函数）

对每个星期，取该星期锚点上的课程片段，按 `(page, x)` 升序；同页同 x 的两个课程片段 → 违约。

1. 字号 9 的片段开启或延续"课程名"；遇到字号 9 而当前记录已有详情行 → 开启新记录。字号 8 的片段追加到当前记录的详情。
2. **跨页续接只在相邻页之间**：第 p 页某星期序列开头的详情行，只能续接该星期第 p−1 页最后一条记录，且该记录详情尚未完整（第 4 条）；
   否则（开头孤立详情、隔页续接、前一记录已完整）→ 违约。
3. 课程名 = 课程名行按序连接，去掉末尾的一个类型标记（`★☆○●◆◇` 之一；单独成行或附在名称末尾同一规则）后去首尾空白；为空 → 违约。名称内部空格保留。
4. 详情 = 详情行按序**直接连接**。必须整体匹配 `^\((\d+)(?:-(\d+))?节\)([^/]+)/.*学分:\d+(\.\d+)?$`；以"学分:数字"结尾是记录完整的判据。
   不匹配 → 违约。遇到下一条课程名、或该星期序列结束时，当前记录必须已完整。**本模板不支持学分数字被分页截断**（会误拒，不会错收）。
5. 核对：在**每条记录连接后的完整详情**上数 `(N节)` / `(N-M节)` 结构标记，每条恰好 1 个（跨片段的标记按连接后计）；课程名连接后含结构标记 → 违约；每个课程片段恰属于一条记录。
6. 课程：`weekday` = 星期序号（星期一为 1），`periods` = `N` 或 `N-M`，`weeks` = 正方周次原文（M18 周次表达式本来就接受项后的 `周` 与 `(单)` / `(双)`），
   随后由 `semester_from_mapping` 按 M18 规则校验，再按 `contracts/timetable_import.md` §3 规范化封装。

## 4. 命令（`ky timetable import-pdf FILE --school ID --label L --week1 D [--weeks N]`）

- **`--weeks` 缺省**取所有课程周次表达式里**各项原写法的上界**（奇偶过滤之前）的最大值（sol 231 P3）：例如 `1-16周(单)` 的上界是 16，不是 15。
  给出时由 M18 按"先查每项上界 ≤ N、再过滤奇偶"校验，因此 `--weeks 15` 对 `1-16周(单)` 违约，`--weeks 16` 接受。
- 学校档案 `system` 不是 `zfsoft` → 违约（换模板需新适配器）。
- PDF 原始字节只读一次：同一份字节用于 `source.sha256` 与片段提取。
- 之后同 `contracts/timetable_import.md` §4 第 11–12 条：结果为空拒绝；只校验候选学期本身；隔离检查后发布暂存；打印摘要与第 1 周网格。
- 暂存 `source.adapter` = `zfsoft_pdf`，`source.sha256` = PDF 原始字节摘要；不记录文件名。

## 5. 测试

- 解析层（合成片段，不含任何个人数据）：按 §2 模板构造的正常课表；标签 y 递减或不在同一 x（不符合本模板）违约；跨页续写；类型标记单独成行 / 附在名称末尾；`(单)` / `(双)`；单节 `(3节)`；
  残片（详情不以学分结尾）、未知片段、标签缺失 / 不等距、同页同 x 冲突、开头孤立详情、隔页续接各一例违约；`(…节)` 计数不符违约；
  sol 231 的 P1 两例（页眉区 9 号字落在锚点上；非课程片段含 `节)`）、P2（续页重复星期标签；页面尺寸或旋转不同）、P3（缺省周数取原写法上界、显式 15 拒绝 16 接受）；
  锚点差值超出 1.0 范围违约；结果不依赖片段输入顺序。
- 片段层：本机有个人 PDF 时"能取出片段且解析成功"，缺文件 skip（个人数据，`contracts/workspace.md` §2.6）。
- **本机验收（不入库）**：决策者在本机把用户这学期的 PDF 导入结果与现有课表同学期比较，报告只写"一致 / 不一致 + 条数"。
