# 端口规格：M16 本机网页（首版："今天"页 + 两个表单）

> 决议来源：用户 2026-10-02（见 `contracts/today.md` §7）。状态：sol 273 FAIL → 274 FAIL（R1、R2）→ 已改，待实现后初检。取代 `docs/前端设计-范围与待定.md` 的 W1 / W2 待定项。
> 实现：`ky/web/`；契约测试：`tests/contract/test_web_port.py`。数据只经公开端口读写：M33 今日视图（`contracts/today.md`）与 M26 `set_day_minutes`。

## 1. 职责与边界

- 一个只在本机运行的小网站，首版只有"今天"页：看今天的时间分配、要复习哪几项、每项做哪道题，并能
  **改某天的可用分钟**、**记录今天的做题结果**。其余操作（学完入队、补改编题、复盘、路线）仍由 AI 在对话里运行命令完成。
- 页面每次请求都从登记的文件重新读取（经 `load_today`），**不读投影**、不缓存；所以 AI 在对话里写完文件后，刷新页面即见。
- 只用 Python 标准库（`http.server`），不新增依赖；页面是服务端渲染的 HTML + 内联 CSS，**不依赖 JavaScript**（表单是普通 `<form method="post">`）。
- 取代早期决定 B5 / B11 中"Web 首版只读"一句：网页可以写，但只能写这两样，且都经现有校验（M26 / M13 管线）。投影仍只读（③ 不变）。

## 2. 命令

```
py -3.12 -m ky web [--port N] [--no-open] [--workspace W]
```

- 只绑定 `127.0.0.1`（**没有** `--host` 选项）；`--port` 缺省 `8730`，`0` 表示由系统分配（测试用）。
- 启动时加载注册表一次以确认可用（找不到或无效 → 契约错误退出 2，同其他命令）；端口被占用 → 契约错误退出 2，提示换 `--port`。
- 启动后打印一行 `http://127.0.0.1:<端口>/`，并在未给 `--no-open` 时用 `webbrowser.open` 打开；Ctrl+C 正常退出（退出码 0）。
- 用 `ThreadingHTTPServer`（浏览器的预连接 / 闲置连接不会卡住后续请求，sol 273），**每个 POST 从解析请求后到重新读取、校验、写入结束全程持同一把进程内锁**，
  网页自身不会并发写；这不防对话里同时运行的 CLI（沿用 S16 / S19 登记）。
- "今天"取系统日期，每个请求在装配层取一次传给 M33；POST 在**拿到锁之后**再取（排队的请求不会拿着过期日期）。

## 3. 页面 `GET /`

可选查询参数 `date=YYYY-MM-DD`（只读查看别的日子；格式不对 → 400 页）。缺省为今天。页面内容（全部来自 `load_today` 的映射，按此顺序）：

1. **标题行**：日期与星期；查看的不是今天时显示"只读：不是今天"及"回到今天"链接。
2. **冻结**（`preflight.freeze` 存在时置顶）：积压分钟、触发阈值，与"请让 AI 运行 `ky resume`"。
3. **今天的时间**：总分钟及来源（手填 / 课表 / 基数 / 配置，中文显示）、基数及来源、课表（第几周、大节数、空闲分钟）、
   路线阶段名、复习软 / 硬上限、各科新学分钟；路线配额启用时另列各科复习配额与已用（未启用不显示，不写 0）。
4. **今天的复习**：`reviews` 每项一行：知识点标题、科目、档位（学过 / 掌握中 / 已巩固 的中文名）、题目：
   改编题显示题面与选项（不显示答案，答案放在可展开的 `<details>` 里）；真题显示题号；缺题显示"还没有改编题，请让 AI 补题"。
   另列延期 / 无法安排的条数（来自 `preflight`）。
5. **记录今天**（§4 表单 B）或已记录的结果（`recorded` 存在时，只读列出每项结果与学习分钟）；`recorded.advanced` 为假时置顶提示
   "已记录，复习队列未推进"与补推进按钮（§4 表单 C）。
6. **改可用分钟**（§4 表单 A）。
7. **复盘**（`pacing` 非 null 时）：下次复盘日、未出报告的周期（有则提示"请让 AI 出复盘报告"）。

所有来自数据的文字（标题、题面、选项、答案、错误消息）一律按 HTML 转义后输出——题面里的 `x<0` 之类公式是正常数据（sol 273）。
页面中文；文字与颜色适配浅色 / 深色（`prefers-color-scheme`）；手机宽度可用；不显示课程名与学校名（课表只显示第几周、大节数与空闲分钟）。

## 4. 表单与 `POST`

三个表单都在成功后 `303` 重定向回 `/`（附 `?msg=` 的固定短语键：`saved` "已保存"、`cleared` "已清除"、`recorded` "已记录"、`advanced` "已推进复习队列"、
`already_advanced` "已经推进过，无需再补"），失败返回 `400` 页：显示契约错误的中文说明与"返回"链接，不出现 traceback。
写入前的校验拒绝不写任何东西；记录管线中途失败按 M33 §4 阶段表说明**已经写下了什么**（按异常的 `stage` 区分，不按消息文字）。
未预料的异常 → `500` 页（简短说明，详情写 stderr），同样不出现 traceback。
请求体只接受 `application/x-www-form-urlencoded`，大小上限 64 KB；未知字段拒绝（400）。

**表单 A：改可用分钟** `POST /availability`：字段 `date`、`minutes`（整数）或 `clear=1`（二者恰好其一）。保存与清除做成**两个独立的表单**，
不靠 JavaScript 区分按钮。
- `date` 必须 **≥ 今天**（过去的日子是事实，不改）；`minutes` 0–1440。
- 调 M26 `set_day_minutes(workspace.availability, date, minutes | None)`。`state.availability` 未登记 → 表单不显示，POST 返回 400"未登记可用时间文件"。
- 表单附近写明：填了的那天优先于课表和基数；清除后回到课表 / 基数；保存会按规范格式重写文件，文件里的注释不保留。

**表单 B：记录今天** `POST /record`：字段 `date`、`view_hash`、每项 `outcome.<review_id>` ∈ {`correct`, `partial`, `incorrect`, `skip`}、可选 `study_minutes`。
- 只在 `date` 等于**处理该 POST 时**的今天时接受，否则 400"只能记录今天"（跨午夜提交的旧页面因此被拒，不写）。
- `skip` 的项不进 `outcomes`。调 M33 `record_day(..., expected_view_hash=view_hash)`；过期、已记录等错误按 M33 原文显示。
- 每项单选缺省为"没做"；按钮文字"记录今天（一天只能交一次）"。
- **缺题项**（sol 273 M3）：旁边写明"没有题目：先默写，再对照笔记；下面选的是对照后的结果"，选项文字为"对照后：对 / 半对 / 错"；没对照就选"没做"。
- 303 之后刷新或浏览器回退再提交：完成事件已存在 → 400"这一天已经记录过"，不会推进第二次。
- `stage = freeze_written`：写明"冻结已触发并记下，但今天的记录没有保存，请排除故障后重新记录"；表单 B 仍可用。
- `stage = event_written`：写明"已记录，复习队列未推进"，并给出表单 C。

**表单 C：补推进** `POST /advance`：字段 `date`（任何有已存完成事件的日子；没有事件 → 400）。调 M33 `advance_recorded_day`；
本次有推进 → `msg=advanced`；全部是重放 → `msg=already_advanced`。回退重交也只会得到后者，不会再推进。

**页面上的"今天"不在服务启动时固定**：跨午夜后刷新即换到新的一天。

## 5. 不变的部分

- 不改任何 CLI 输出与数据格式（M33 §6 的逐字节对照覆盖 CLI，唯一例外是 M33 §4.1 推进失败分支多出的恢复命令行）；不改投影与 `ky.projection.serve`。
- 网页不提供：学完入队、补题、停用题、复盘、路线、冻结重启。这些仍由 AI 在对话里运行命令。

## 6. 契约测试要点

在临时工作区（复制注册表与最小数据）里：
- `GET /` 返回 200，含当天总分钟、入选复习项标题；冻结、缺题、已记录三种状态各有断言。
- 表单 B 成功写出的完成事件字节与同输入下 `ky day-plan record --done` 写出的相同，队列推进相同；过期 `view_hash`、重复记录、非今天、未知 `review_id` → 400 且不写文件。
- 注入推进失败：事件保留、页面显示未推进；表单 C 之后队列与一次成功记录的结果相同；再提交表单 C 得到 `already_advanced` 且不再推进。
- 注入"冻结已写、完成事件写失败"：冻结事件保留、没有完成事件；排除故障后表单 B 可重交成功，且不多写冻结事件。
- 题面含 `<`、`&` 时页面转义正确。
- 表单 A：今天 / 将来写入并能被 M26 读回；过去日期、越界分钟、`minutes` 与 `clear` 同时给 → 400 且文件字节不变。
- 服务只绑定 127.0.0.1；端口占用 → 退出 2。测试用 `--port 0`、`--no-open`，在线程里起服务。

## 7. 安全登记（不在本包修，汇入 `docs/安全风险登记.md`）

- HTML 注入：已要求统一转义（§3），恶意构造的题面不再单列。
- 没有 CSRF 令牌与身份认证：本机任何进程或网页都能向 `127.0.0.1:<端口>` 发 POST。缓解：只绑定本机、只有两种写入且都经校验。开源前加每进程随机令牌。
- 服务只在用户运行命令期间存在；不做 HTTPS。

## 8. 第二版：三个只读页面（用户 2026-10-08）

用户 2026-10-08 定：⑥ 要做完，第二版**只读**——补上首版明确留下的三块（复习队列 / 路线与复盘 / 三张图）。
**本版不新增任何写入路径**：`/` 的两类写入（§4 表单 A / B / C）原样保留，本节三个路径只接受 `GET`。

### 8.1 共同约束

- 三条路径：`GET /queue`、`GET /route`、`GET /charts`。`/queue` 与 `/route` 接受可选 `date=YYYY-MM-DD`（校验同 §3），
  只接受一个 `date` 查询字段；缺省时每个请求取一次系统日期，该请求的全部计算用同一个 `day`。
  `/charts` 与文件 URL **不接受任何查询字段**：未知 / 重复查询字段或非法日期 → **400**。
- 上述入口与 `/charts/<文件名>` 的**所有非 GET 方法** → **405**，带 `Allow: GET`，且不进入数据装配或写入管线；
  未知路由 → **404**（sol 291 M5）。
- 找不到 / 无效注册表在**启动时**按 §2 退出 2；运行中读取已登记来源失败或来源无效 → 转义后的契约错误 **400** 页面；
  可选键未登记与合法空数据按各页规则返回 200；未预期异常 → **500**，详情只写 stderr，不终止服务、不向页面暴露 traceback。
  **全部 GET 与拒绝请求都不创建目录、锁、缓存、报告或任何工作区文件**（sol 291 M5）。
- 与 §3 同一套外壳与风格：服务端渲染、无 JavaScript、内联 CSS、浅色 / 深色、手机宽度、全部外部文本转义；
  每页顶部有"今天 / 复习队列 / 路线与复盘 / 图表"导航与"回到今天"链接；不显示课程名与学校名。
  **例外**：`/charts` 原样提供的离线图表 HTML 及其既有 Plotly 脚本（§8.4）不加导航、不改 HTML、不转义其文件字节；
  §1 的"不依赖 JavaScript"据此限定为**本项目自己渲染的页面**（sol 291 M4）。
- 数据只经既有端口读，**不读投影、不缓存**；一次请求内每个来源只读一次（沿用 M33 装配的同一口径，`AGENTS.md` 已知缺陷 #2）。

### 8.2 `GET /queue` 复习队列页

数据：M33 `load_queue_view(workspace, day)`（`contracts/today.md` §8）——与"今天"页共用同一套来源装配与 M9 预检。
**同日且来源内容相同**时，两页的 `budget`、M9 入选顺序与各桶计数 / 分钟必须一致；两次请求之间 AI 改了数据则允许变化（sol 291 M2）。

按此顺序显示（冻结提示存在时放在第 1 项**之前**）：

1. 日期与"今天的时间"摘要：总分钟与来源（手填 / 课表 / 基数 / 配置）、复习软 / 硬上限（路线配额启用时用配额）。
2. 冻结（`freeze` 存在时）：积压分钟、阈值、"请让 AI 运行 `ky resume`"。
3. **五个桶的条数与分钟**：`selected`（今天入选）、`deferred`（延期）、`unschedulable`（单项太大，提示拆分）、
   `scheduled_ahead`（未到期）、`unreachable`（过期但不可选）。列名与 M9 一致，中文显示。
4. **今天入选的每一项**：review_id、知识点标题、科目中文名、档位、`due_date`、逾期天数、`defer_count`、遗忘次数、预计分钟。
5. **积压**：与 `backlog` 同口径（`deferred` + `unschedulable` + `unreachable`）——注意它**不等于** M9 的
   `backlog_minutes`（后者只含 `deferred`）。按科目汇总条数与分钟；明细取 `backlog.details`（最多 20 条），
   其余只给 `remaining_count`；延期的项标注 `defer_count` 是"本次预检延期后计数"（预检会 +1，且不写回）。
6. 未到期项按 `ahead` 口径：条数 + 最近 3 个到期日（升序去重），不列明细；它与 `scheduled_ahead` 桶**不是一回事**
   （后者只含预检里被排到未来的项）。

合法空队列 → 200，显示"复习队列是空的（学完知识点后用 `ky learn` 入队）"；`state.review_queue` **未登记属于无效注册表**，
按 §2 在启动时退出 2、不构造视图（目录 / manifest 尚不存在按既有 M13 空库处理；sol 291 M1）。

### 8.3 `GET /route` 路线与复盘页

数据（各自只读一次，sol 291 M3）：路线从 M11 `RoutePlanStore.current()` 读一次；配置经公开 `load_config(workspace.require('settings.exam_config'))`、
复盘设置经 M28 `settings_for_workspace(workspace)` 各读一次；当前基数经 M8 `daily_base_minutes(day, config, route, settings)` 计算。
复盘周期经 `cycle_for_date`；未报告周期与已保存报告经 `load_pacing_report_state(settings, day, workspace.write_target('state.plans'))` 一次取得。
**无 `settings.pacing` 时不读取报告**；不调用报告生成 / 提交端口。

1. 路线：`route_id`、修订号、**规划输入标识** `stage1_input_hash` 前 12 位、起始日、目标考试日、
   剩余天数 `max(0, (target_exam_date - day).days)`。不把规划输入标识冒称提交来源。
   未登记路线或 `current()` 为 `null` 都显示"还没有路线，请让 AI 按 `prompts/route_planning.md` 写提案"。
2. 阶段表：序号、起止（右开）、标签、各科复习分钟、阶段 `targets`（没有则写"未设目标"）；
   当前阶段 = `start <= day < end_exclusive`，无命中则不高亮。
3. 复盘：当前基数与来源由 M8 返回；周期显示 `start` 至 `end` 终日，`next_review = cycle.end`；
   `cycle` 为 `null` 时显示"复盘尚未开始"、下个复盘日留空。未报告周期按终日升序显示；
   最近报告取返回报告映射里**最大周期终日**那个键，显示 `cycle.end`、`base.min/max/mean` 与 `reviews` 各科完成统计，
   **不声称是配额变化**；没有报告就写"还没有复盘报告"。

未登记 `settings.pacing` → 复盘一节显示"未登记复盘设置"（不是错误）。

### 8.4 `GET /charts` 三张图入口

数据：注册表 `products.charts` 目录（`ky chart week / progress / ability` 的离线 HTML 输出）。

- `GET /charts` 仅枚举**直接位于登记目录**、名字匹配 `week--*.html`、`progress--*.html`、`ability--*.html` 的**普通文件**；
  按类别分组、同类按修改时间倒序（同修改时间再按文件名，sol 291 建议）；每条显示文件名与修改日期，链到 `GET /charts/<文件名>`。
- `GET /charts/<文件名>`：文件名先按 URL 路径解码；**拒绝**路径分隔符、`../`、子目录、符号链接及其它名字 / 扩展名 → **404**。
  命中时按文件字节原样返回，`Content-Type: text/html; charset=utf-8`，并给正确的 `Content-Length`。
- **另仅允许精确名 `plotly.min.js` 的普通文件**（离线图表 HTML 引用同目录的它）：按字节返回，
  `Content-Type: application/javascript; charset=utf-8`，**不列入入口列表**（sol 291 M4）。
- 登记目录按 `Workspace` 的路径包含规则解析，目标解析后必须直接位于其中；列表与下载用**同一套**筛选规则；
  命中文件丢失 → 404；读失败按 §8.1 的请求错误规则处理。
- `products.charts` 未登记 → `GET /charts` 返回 200，文字"未登记图表目录，请让 AI 检查注册表"，且所有文件 URL 返回 404；
  目录不存在或没有匹配 HTML → 保留生成命令提示；路径存在但不是目录 → 契约错误；
  匹配 HTML 存在但 `plotly.min.js` 缺失 → 入口提示重新生成图表，**不在 GET 里修复**。
- **不做在线渲染、不调用 `ky chart`、不补写资源**；`ky chart` 的输出格式与 `products.charts` 的登记不变。
