# Round 35：408 题目正文重新抽取与对齐核验

## 结论

已从 2023—2026 四份 quiz HTML 重新抽取 188/188 道题，每年均为 47/47；HTML **确实含有综合题 41—47 的正文**。前一版的两个关键前提均不成立：PDF 无文本层不代表 HTML 无题面；把 HTML 扁平化后看不到稳定的“行首题号”，也不代表 DOM 没有题号锚点。四份 HTML 的主内容区均有且仅有 `h5 id="1"` 至 `h5 id="47"`，综合题正文位于 `h5 id="41"` 至 `h5 id="47"` 与各自 `answer-container` 之间。

本轮没有按块顺序猜题号，也没有使用会静默截断的 `zip(entries, units)`。索引和 HTML 都先按题号建键，再逐个读取 `1..47`；题号缺失、重复、类型不符、边界不存在、选项不是完整 ABCD、答案交叉核对不一致时，脚本都会立即失败。

## 对用户质问的正面回答

题目文本找得回来，而且就在现有四份 HTML 中。知识点映射并非来自一批已经丢失、只能靠模型回忆的题面；页面对 188 道题都保留了显式题号、正文、题目标签/知识点入口和答案/解析控件。前一阶段没有还原出来，是因为读取了无文本层 PDF，之后又丢弃了 HTML DOM 结构，仅依赖扁平文本中的 ABCD 块并按顺序硬配，导致综合题天然遗漏且选择题可能错位。

## 抽取方法与边界

每题按以下机械规则抽取，不生成或补写任何内容：

1. 在 `.td-content` 内以 `h5[id="题号"]` 定位题目。
2. 选择题读取该标题之后、同题 `.choice-container` 之前的题干；四个选项只取 `.choice-label` 与 `.choice-text`。
3. 综合题读取该标题之后、同题 `.answer-container` 之前的所有段落、代码、表格和图示文本；不读取解析正文。
4. `answer` 始终取自 `408_index_<year>.json`，DOM 答案只用于交叉验证，不反写或推断答案。
5. 表格、代码和 SVG 中可访问的文字被序列化到文本；无可访问文字的图形明确写成源图提示并标低置信，不用模型知识补图。
