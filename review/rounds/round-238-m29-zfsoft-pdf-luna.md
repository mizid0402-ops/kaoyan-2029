# 第 238 轮：M29 正方 PDF 导入适配器

## 改动

- 新增 `ky/timetable_io/zfsoft_pdf.py`：冻结的 `Page` / `Fragment` / 模板对象，`pypdf` 字节提取，纯函数片段解析、周次上界计算，以及候选学期校验与暂存发布入口。
- 修改 `ky/__main__.py`：增加 `ky timetable import-pdf FILE --school ID --label L --week1 D [--weeks N]`。PDF 路径只读一次；隔离状态检查一次后传入导入操作。
- 新增 `tests/contract/test_timetable_io_zfsoft_pdf.py`：仅用合成片段覆盖版式、锚点、分类、结构、跨页续接、输入顺序与周数边界；本机 PDF 用例只从 `KY_TIMETABLE_PDF` 读取，未设置时跳过，不写入文件。
- 新增本报告。未修改 IO1 文件、M18、规格、注册表或任何数据文件。

## 实现要点

- 解析阶段依规格顺序执行：页面一致性、星期标签、区域隐式划分、锚点、片段分类、页眉结构字符拒绝、按星期和页码切分记录、详情核对。周标签 x 以最小值和最大值中点作为 `Lx`；锚点差值用有效集合的最小 / 最大值中点，空集合直接违约。
- 每个星期跨页只保留紧邻上一页的未完成记录；中间空页、该星期空页、孤立详情和已完成记录后的详情均拒绝。错误只带页码、坐标、提取序号及阶段，不回显片段文字。
- 课程周次从详情的排课段中提取唯一、带“周”或奇偶标记的候选表达式。缺省周数取表达式每项原上界的最大值，再由 M18 校验；显式周数同样交由 M18 校验。
- 候选学期通过 `semester_from_mapping` 和 `validate_semester_references` 后，构造 `StagedSemester("zfsoft_pdf", ...)` 并调用 IO1 公开 `publish_staging`。

## 未解决的集成阻塞

当前 worktree 的 IO1 `parse_staging_bytes` / `publish_staging` 只允许 `source.adapter: ics`；因此它会拒绝本规格要求的 `zfsoft_pdf`，新 CLI 目前不能成功发布暂存文件。我按任务边界没有修改 IO1 文件，也没有绕开公开发布接口另写一套暂存发布器。完成端到端导入需要先由决策者把 IO1 暂存格式的 adapter 白名单扩展到 `zfsoft_pdf`，同时保持现有 ICS 行为。该接口依赖已在本轮向用户提出选择问题。

另一个规格缺口：上级导入流程要求个人课表已登记时打印每日推算分钟，但本命令没有 `--config` 参数，且 M18 的 `day` 基数必填。本轮只打印课程网格，不臆造基数；若仍要求打印分钟，需要决策者明确基数来源。

## 歧义与选择

- 规格没有指出周次表达式在详情排课段中的精确边界。本轮要求其中恰有一个带“周”或奇偶标记的 M18 表达式；零个或多个候选均拒绝，避免把日期 / 时刻中的数字猜成周次。
- 缺省周数严格使用原写法上界，不在奇偶过滤后取最大值；例如奇数周表达式的上界仍保留为学期周数。
- 每日分钟的基数来源未在 import-pdf 命令参数中给出，因此不打印可能误导的分钟值，仅输出课程网格。未修改规格。
