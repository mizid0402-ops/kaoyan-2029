## 必须改

### M1：M31 §6 引用的 M24 函数名不存在

现有公开端口为 `ky.review.check_questions.candidate_check_questions`（实现第 175 行），不是 `check_question_candidates`。
反例：实现者按规格 import 后调用新增回退参数，会直接 ImportError；或另造端口而未扩展既有调用入口。
改为真实公开名称，并明确在此端口增加参数；缺省保持原行为的要求保留。

### M2：M31 §3 单文件不可覆盖与追加新题互相冲突

反例：首次给一个知识点提交 01、02 两题，之后按“要换题就追加”提交 03；目标仍是同一个 `<knowledge_point_id>.yaml`，`os.link` 必然因已存在失败。
须选定可追加的存储单位与发布规则，例如每题独立不可覆盖文件，或不可覆盖版本文件配登记；不能同时要求同一路径只写一次又更新其 questions。

### M3：M31 §5 的“最近一次以外”会让第三题永远轮不到

反例：题库 01、02、03；先做 01，再做 02。按“排除最近一次、序号最小”下一题又是 01，此后 01 / 02 交替，03 从未做过，也进不了“全部做过”分支。
须明确先选从未引用过的题，再在全部做过后按最近使用时间循环；若只排除上一题，就删去与之冲突的全库轮转承诺并说明第三题的选择办法。

### M4：M31 §4 仅允许叶子，堵住 §5 对合法粗粒度复习项的生成入口

反例：已有 `math1.hs.ch02.requirements` 复习项；包 C 后该节点仍保留且有 item 子节点，M30 §3 允许它覆盖后代。学过档缺题时 §5 给它生成命令，但 §4 提交因非叶子拒绝。
祖先题库回退也无法靠生成祖先题来补齐，因为祖先同样不是叶子。须明确粗粒度项如何生成 / 取后代题，或允许可学非叶子入库，统一生产与消费的节点范围。

### M5：M31 §2 的无真题 AI 兜底在 §3–§5 没有可执行路径

反例：`eng1.appendix.affixes` 是现有可学叶子，三份登记英一索引均无该 ID 映射；树中无 `eng1.appendix` / 科目公共根，§6 回退仍无候选。
§5 提示先生成，但 §3 要求 based_on 非空，§4 又要求全部来自该空候选包，任何提交都无法通过；“照旧可用 AI 巩固题”无法经此流程兑现。
须定义无覆盖时的独立 guided 生成 / 引用路径，或明确导向既有可执行流程；不能给出必定提交失败的补题命令。不要把英一所有根强接后选无关真题。

### M6：包 C 的“258 未提该处改动”会排除已确认错字

反例：2026 转录第 365 行写“一致性(柑&nbsp;合性)”，2022 第 1193 行为“一致性(相合性)”；258 报告已明确登记“相合性→柑合性”。按当前条件，该已知错字反而不能修，进入 `math1.pr.ch21.requirements.item-03` 标题。
须区分“报告确认的转录错字”与“报告确认的考试要求变更”：前者可注明修正，后者保留新版；未确认差异保留 2026 标题并各记原始 quote_ref，不能因报告提过错字而禁止修正。
