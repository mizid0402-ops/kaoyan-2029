# 任务：搜寻「考研英语（一）大纲词汇表」的网上来源

## 背景与要解决的问题

项目已建了一个三年真题（2024/2025/2026）词频库，但**审计后判定它作为"该背什么"的依据不成立**：

- 样本只有三套卷子（约 25,073 词次、3,409 个不同词），而大纲要求的是**约 5,500 词**
- 三套卷子的**选文题材偏斜**，导致 `ai / science / artifacts / digital` 这类题材词排名虚高
- 即三年词频测的是"这几套卷子的题材词"，不是"考研英语的高频词"

**正确做法是「大纲词表打底 + 真题标注热度」。** 现在缺的是那份词表。

用户**不持有**纸质大纲（已确认）。所以走网上检索。

## 你要交付什么

**一份可用的考研英语（一）词汇表（尽量接近 5,500 词），并给出它的来源与权利状态评估。**

## 硬性要求

### 1. 必须有可追溯的来源

每个候选来源记录：
- URL、字节数、**SHA-256（现算）**
- 页面/文件自述的**编制者**（官方？出版社？培训机构？个人整理？）
- **版权/许可声明**（页面有没有写 CC、有没有写"版权所有禁止转载"、有没有声明）
- 是否自称"大纲词汇""官方词汇""历年真题高频词"——**注意区分这三者，它们不是一回事**

### 2. 判据用三条独立的轴，**不要用"权威性"否掉可用资料**

用户明确指出：官方权威资料**因为版权原因拿不到**，而且用户本人正是**因为拿不到权威资料**才做这个项目。
**"非官方所以悬空不用"会让整个方案无法落地。**

所以判据拆成三条**互不推导**的轴：

| 轴 | 问什么 | 用途 |
|---|---|---|
| **① 权威性** | 谁发布的 | **只用于**"能否据此定义考纲"这一件事 |
| **② 准确性** | **对不对**（必须可交叉验证） | 词表/词条质量 |
| **③ 可传播性** | 能否落盘、能否再分发 | 决定能否进项目、能否给 Web 用 |

**三条互不推导。** 一份非官方词表可以 ②高 ③可落盘、只是 ①低——**那就可用，应当落地**。
项目的 `source_tier` 体系原本只服务于 `may_define_syllabus()`，**不要把它套到词表上**。

### 2.1 准确性必须给**可测量的数字**，不是定性评价

对每份候选词表，算出：

- **词条数**（去重后）
- **与三年真题词库的重合率**：该词表的词里，有多少出现在 2024–2026 真题中（分母=词表词数）。
  真题词库在 `F:\workspace\kaoyan-ai-system\data\english_vocabulary\eng1_vocabulary.sqlite`
  （**只读**；注意另一任务可能正在写它，读不到就用报告里说明）
- **与其他候选词表的重合率**（两两），据此判断是否同源转载
- **明显异常**：含臆造词、含句子、含中文释义错位、大小写/屈折形式混乱等

**这些数字才是"准不准"的依据**，不是"来源等级高不高"。

### 2.2 可传播性如实标注，但不作为否决条件

每条记 `may_store` / `may_redistribute`：

- 权利清晰 → 如实写
- 权利不明 → 标 `unknown`，并说明"未知不等于可用，但要知道它不明"
- **不要因为"非官方"或"权利不明"就把它排除在推荐之外**——
  排除与否取决于 ② 与 ③，而 ③ 不明时**可以用"仅本地自用、不对外分发"的方式落地**

### 3. 必须实际取得内容并核对

- **实际下载**，不要只看页面标题或搜索摘要
- 记录**词条数**（去重后）
- 检查是否形如字母序词表（A/B/C… 分节）
- **抽样核对若干词**是否像正常词表（不是句子、不是真题原文）
- 若为 PDF 且无文本层，用 `pypdfium2` 渲染后目视读
- 若需登录/付费才能取全，**如实说明只取到了多少**

### 4. 独立性与可用性

- 判断各候选之间是否**同源转载**（比对词序、注释措辞，给**相似度数值**）
- 每条如实标注 `may_store` / `may_redistribute`；**权利不明时标 `unknown` 并说明，
  但不因此否掉它**——可用"仅本地自用"落地
- **推荐标准 = ②准确性（交叉验证吻合）+ 覆盖够（贴近 5500）**，**不是**"等级够高"

### 5. 找不到就说找不到

**绝不用模型自己的知识去"生成"一份词表冒充检索结果。**
若最终没有找到可采信的来源，**如实写"未找到"**，并列出试过的具体 URL/搜索词与失败原因。

这是本任务最重要的一条纪律：**一份诚实说"没找到"的报告，比一份由模型凭记忆编出来的 5500 词表有价值得多。**
（模型自己生成的词表无法验证、可能含臆造词、也无法标注来源等级。）

## 建议的检索方向

- 搜索词参考：`考研英语一大纲词汇表`、`考研英语5500词汇表`、`2026考研英语大纲附录 词汇`、
  `考研英语大纲词汇 完整版`、`考研英语词汇表 pdf`、`考研英语大纲词汇 excel`、
  以及英文/繁体关键词
- 站点方向：**人教社/高教社官网**、教育部教育考试院、各省考试院、
  高校研究生院公开资料、图书馆编目、公开词库项目（如 GitHub 上的英语词表仓库）、
  Internet Archive、以及出版社的公开样章
- **优先找官方或出版社口径**，其次机构
- 注意：很多"考研词汇"其实是**教辅词汇书**（如"红宝书""恋练有词"），
  那是**出版物正文**，不能直接落盘；要区分"大纲附录词表"与"教辅词表"
