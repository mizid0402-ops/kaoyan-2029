## D. 置信度判据（可计算）

### 1. 单源质量分 `S/9`

- `R` 可达性：HTTP 200 且得到非错误正文/PDF = 1，否则 0。
- `C` 完整度：完整 22 题/整卷 = 2；可覆盖主要题段但有图片、预览或缺题 = 1；只有标题/导航/零散答案 = 0。
- `A` 答案：完整答案键或逐题答案+解析 = 2；只有部分答案 = 1；无答案 = 0。
- `X` 可抽取性：可直接抽文本/稳定下载 = 2；需要 OCR/页面内预览/JS = 1；无法取得题目 = 0。
- `P` provenance：发布方/载体/文件哈希可记录且不是明显镜像 = 2；发布方可区分但共同上游未知 = 1；来源不明/同页复制 = 0。

### 2. 双源置信度 `C_pair`

对齐后定义：

```text
question_match = 题干+选项规范化后相同的题数 / 已对齐题数
answer_match   = 答案相同的题数 / 已对齐且两边都有答案的题数
agreement      = 0.6 * question_match + 0.4 * answer_match
independence   = 1.0（发布方、域名、载体均不同且无镜像证据）
               = 0.5（发布方不同但可能共享转载源）
               = 0.0（同一站点、同一文件或明显镜像）
C_pair         = 0.4 * min(S1,S2)/9 + 0.4 * agreement + 0.2 * independence
```

阈值：`>=0.85` 高；`0.70–0.849` 中高；`0.50–0.699` 条件可用；`<0.50` 不可作为入库主件。若是回忆版，额外将 `independence` 上限设为 0.5，且年份标签必须写“回忆版/重构版”。数学公式不能只用 OCR 字符串比对：至少做一次符号规范化、数值代入或人工回算。

### 3. 进入本地语料前的硬门槛

1. 保存纯试卷和答案解析为两个文件，记录 URL、抓取日期、HTTP 状态、文件大小、SHA-256。
2. 题号覆盖必须是 1–22；数学一的选择题 1–10、填空题 11–16、解答题 17–22 缺一项就标 `incomplete`。
3. 每套至少保留一份题面源和一份答案源；两者若来自同一 PDF，只能算单源，不能算交叉验证。
4. 冲突不覆盖：把两个版本都保留，建立 `year/question_id/field/conflict` 记录，人工裁决后再生成 canonical 版本。
