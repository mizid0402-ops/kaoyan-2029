## B. 数学一专项（缺口解决方案）

### B.0 根因：不是 JS 渲染，不是反爬，不是下架 —— 是**载体错配 + 引流空壳**

我逐一证伪了任务书列出的三个假设：

| 假设 | 判决 | 证据 |
|---|---|---|
| JS 渲染，需要浏览器 | **证伪** | xdf.cn 确是 Nuxt SPA，但我**已经把 `window.__NUXT__` 载荷完整解出来了**（`nuxt_probe.txt`）。正文全在里面，一共 19–25 段中文，**全是宣传语**，其中 2025 页明写「考后更新，**敬请期待**」。**用无头浏览器渲染出来的仍是同一批营销文案** —— 上浏览器是纯浪费。 |
| 反爬 | **证伪** | 全部 HTTP 200，无验证码、无 403、无滑块，正文完整返回。 |
| 已下架 | **证伪** | 页面存活，标题正确（`2026年考研数学一试题及答案解析完整版（新东方版）`），只是正文从未填入题目。 |

**真正的根因（两条，互相印证）**：

1. **新东方的 CMS 是纯文本发布系统，装不下数学公式。**
   决定性反证：**同一个 koolearn CMS、同一时间窗、同一栏目模板**下，
   `kaoyan.koolearn.com/20221224/1578630.html`（2023 **英语一**）**正文有 31557 字真题原文**，
   我逐字核对到真实完形填空段落。
   → 英语是纯文本，活下来了；数学是公式，活不下来。
   所以新东方对数学一只发**引流文案**，把人导向 `thematic/307` 注册墙和微信扫码（该页 `扫码` 出现 63 次）。

2. **真正有数学一的站点，一律用「整页图片」发布。**
   这正是所有纯文本探针（你的和我的）都报"空"的原因 —— 题目不在文本层，在 `<img>` 里。
   我据此重新扫描候选站的 `<img>`，立刻找到了内容，并**下载图片用视觉核对确认**。

> **给编排器的可执行结论**：数学一不要再在新东方上花时间，也不要上 Playwright/Selenium。
> 换站点 + 按图片抓取 + OCR。

## D. 置信度判据（可计算）

不用星级。每个「科目-年份」算一个 0–100 的 `conf` 分，四项加权求和。

### D.1 分项定义

**S1 内容存在性（0–30）** —— 自动可算
```
opt_markers  = 正文中 A./B./C./D. 计数
ans_markers  = 正文中 (正确答案|【答案】|参考答案)[：:]?[ABCD] 计数
page_imgs    = 正文容器内 非站点chrome 的 <img> 数
S1 = 30  若 ans_markers >= 0.9 * 该卷应有客观题数
   = 25  若 page_imgs >= 8 且抽样图经人工确认含题干
   = 10  若 0 < 证据 < 上述阈值
   =  0  若 opt_markers==0 且 ans_markers==0 且 page_imgs==0     ← 空壳，直接废弃
```
> 阈值依据：408/数学一每卷客观题数已知（408=40 单选；数学一=10 单选+6 填空）。
> 新东方全部 6 个数学一页面 S1=0。杂货铺 2023/2024 `40/40 = 1.00` → S1=30。

**S2 来源独立性（0–30）** —— 两个来源 `X`、`Y` 之间算
```
ind = 0
ind += 10  若 机构不同（不同公司/组织实体）
ind += 10  若 载体不同（HTML文本 / 页面图片 / PDF文本层 / 扫描件）
ind += 5   若 域名与CDN均不同
ind += 5   若 发布时间差 > 24h 或采集路径不同
S2 = ind   （单源 → S2 = 0）
```
> 注意：**新东方 koolearn.com 与 xdf.cn 是同一集团，ind 最多 10**，不构成独立验证。
> 用户清单把「新东方」和「第三方 PDF 站」配对，而第三方站的 PDF 往往**就是从机构版转存的**，
> 存在**同源伪装**风险 —— 见 E.6。

**S3 一致性（0–30）** —— 需要实际比对
```
ans_agree = 两源答案字母序列一致的题数 / 总题数
fp_agree  = 选项指纹一致的题数 / 总题数        （指纹定义见 D.2）
S3 = 30 * (0.5*ans_agree + 0.5*fp_agree)
```

**S4 载体质量（0–10）** —— 影响 OCR 可用性
```
S4 = 10  原生文本层 PDF / 结构化 HTML（零 OCR 误差）
   =  7  无水印整页图，短边 >= 1000px
   =  4  有水印 或 短边 < 800px
   =  1  仅 OCR 后文本（已损坏）
```

`conf = S1 + S2 + S3 + S4`

### D.2 选项文本指纹（具体算法）

数学公式 OCR 后必然失真（book118 的 `贝IJ`、`尸(x)` 就是实例），所以**不要对公式做精确匹配**。
只对**中文骨架**做指纹：

```
fingerprint(option_text):
    1. 删除所有 ASCII、希腊字母、数学符号、上下标、空白
       （即：只保留 CJK 统一表意文字 U+4E00–U+9FFF）
    2. 结果串取前 12 个汉字
    3. 若长度 < 4 → 该题标记 fp_unusable（纯公式选项，无法指纹）
两源一致 ⟺ 两个指纹的编辑距离 <= 1
```
> 在 B.2 的 2025 Q1 上实跑：
> 启航「是的极值点也是的极值点」 vs book118「是的极值点，也是的极值点」→ 距离 0（去标点后）→ 一致。
> 这个算法能穿透 book118 把 `f(x)` OCR 成 `/(x)`、把 `y` 认成 `v` 的噪声。

### D.3 阈值

| conf | 等级 | 处置 |
|---|---|---|
| **≥ 85** | `verified` | 直接进标注管线 |
| **70–84** | `probable` | 进管线，但抽查 20% 题目 |

## E. 不可用/降级清单

**E.1 408 综合应用题完全缺失（用户清单未提及，影响最大）**
杂货铺四个年份页面中 `综合应用题`/`应用题`/第 41–47 题标记**均为 0**。
408 满分 150 = 40 单选(80) + 7 综合应用题(70)。杂货铺只覆盖 **53% 分值**。
→ 大题必须从你已有的厦门工学院 PDF 扫描件走 OCR，而那批**无文本层**，需要真 OCR + 人工校对。

**E.2 408 2026 答案分布异常，且无第二源**
44 个答案标记（超出 40），且 **D 占 17/44 ≈ 39%**（均匀期望 25%）。
四个年份页面里**没有任何 `回忆版`/`重构` 字样** —— 该站**不自述来源**，这是透明度缺陷。
2026 是考后最易混入回忆版的一届，而王道 Scribd 有订阅墙、Bilibili 是视频、你的 PDF 只到 2025。
→ **408 2026 目前无法交叉验证**，必须标 `single-source` 且人工逐题复核。

**E.3 数学一 2026 只有启航单源，且画质最差**
中国教育在线**尚未发布 2026 数学**（我抓了 `shiti/shuxue/` 索引页和 `index_2.shtml`，
最新只到 2025-08-28 发布的 2025 三套）。eol 有 **约 8 个月的回填延迟**（2025 年卷在 2025-08 才上线），
→ 2026 年卷预计要等到 2026 年秋才在 eol 出现（即：**可能就在最近，值得复查一次**）。
启航 2026 图片仅 369×558 且满版水印，S4=4。→ 2026 数学一**建议暂缓入库**，或先只做题号/知识点标注、不做全文 OCR。

**E.4 我自己的一个误判（已自我推翻）**
初轮探针在 `sjds.net` 上报出 **140 个选项标记**，看起来像有大量题目。
复核后：`0 个答案标记、0 个 MCQ 结构块`，那 140 个是页面导航与推荐列表里的**正则误报**。
`sjds` 实为夸克网盘链接聚合页，且页面时间戳是**我抓取当天动态生成**的（SEO 农场特征）。
→ **不可作答案源**，用户清单「不建议将其作为答案唯一权威来源」的判断是对的，但实际比这更差：它连题目都没有。

**E.5 suanzan 自述与实际不符**
首页自称「数学一 38 套、覆盖 1987–2026、官方原版·公益免费」，
但数学一可见列表是 2026/2023/2022/2021/2020/2019 —— **2024、2025 不在其中**。
全部资源经**夸克网盘**分发，需要交互式登录/客户端，**不可脚本化**。→ 只能人工备用。

**E.6 「新东方作答案基准 + 第三方站下 PDF」这个组合本身有结构性缺陷**
用户清单第八节建议此组合。但：(a) 新东方数学一根本没有答案内容；
(b) 第三方站的 PDF 极可能**就是某机构版的转存**，若恰好转的是新东方版，
则「交叉验证」变成**自己验证自己**（同源伪装）。
→ 交叉验证必须**先确认两源的原始出处不同**，而不是只看域名不同。
中国教育在线的可贵之处正在于它**明确标注了原始出处**（2023=海文考研、2024/2025=掌上考研、2022=新文道、2021=文都），
