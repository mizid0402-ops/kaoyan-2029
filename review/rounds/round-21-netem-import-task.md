## 要交付什么

### 1. 把 NETEM 词表导入英语一词汇库，作为**独立来源**

现有库：`data/english_vocabulary/eng1_vocabulary.sqlite`（**只读参考它的结构，不要破坏它**）。
**建议新建一张表**（而不是改现有 `words` 表），例如：

```
source_wordlists(source_id TEXT PRIMARY KEY, name, url, sha256, licence, retrieved_on)
source_entries(source_id, word_form_norm, rank, source_freq, category, subcategory, other_spellings)
```

理由：**这是另一份来源，不是现有三年真题词库的一部分**；混进同一张表会让"来源"这个维度丢失，
而多源合并**恰恰需要保留来源**。

- `word_form_norm`：小写折叠后的键（注意大小写折叠后有 5528 个唯一值，不是 5530）
- **不要**把 `释义` 写进库

### 2. 与现有三年真题词库做**交叉验证**，给可测量的数字

这是本次最重要的产出。算出：

- **重合率**：NETEM 的 5528 个词里，有多少出现在现有的三年真题词库中（`words` 表，`is_stopword=0`）
- **反向覆盖率**：三年真题词库里**不在** NETEM 中的词有多少（这些可能是超纲词、专有名词、
  或**分词伪影**——顺便能验证我们之前的清洗质量）
- **按词频分层的重合率**：NETEM 词频最高的 500 / 1000 / 2000 词，各自在真题里出现过多少

**这些数字就是"准确性"的依据**，比任何来源等级都有说服力。

### 3. 与英语一现有来源的关系判断

英语一现有：`eng1-outline-toc-aus-zxhsd-2026`（**只有目录，没有词汇附录**）。
所以这两份来源**覆盖的层次不同**（一份是考纲结构、一份是词表），**不是同源转载**——
请在报告里确认这一点，并说明**它们能各自支撑什么结论**、**不能支撑什么**。

### 4. 落盘与登记

- 词表数据落进库（只含上表列出的字段）
- **在报告里提出**：这条来源应如何登记（`resource_id`、`source_tier`、`rights` 各字段的建议值），
  **但不要自己改 `data/materials.yaml`**（主控统一处理）

### 5. 验证

- 新表的完整性校验（条数、唯一键、null 检查）
- **变异测试**：改一条 rank、删一条 entry、把大小写折叠键写错，验证器必须变红；给还原哈希
- `py -3.12 -m unittest discover -s tests -q` 必须全绿（现有基线见下）
- 报告 `review/rounds/round-21-netem-import-claude.md`

**注意现有基线**：词汇库那批测试（`tests/test_eng1_vocabulary.py`）此前有 2 条报错，
