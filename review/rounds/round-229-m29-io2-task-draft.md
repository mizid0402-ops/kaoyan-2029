# 第 229 轮任务书（草稿，IO1 合并后定稿）：WP-IO2 ics 导入 + 导出到日历（gpt-6-luna）

规格 `contracts/timetable_import.md` §4、§6、§7。依赖 IO1 的 M18 公开入口、隔离检查与暂存发布。

定稿时写进任务书的实现口径（sol 227 细节 1、3、5、7）：

1. 域比较一律半开：`week1 <= 本地日期 < week1 + 7N`，"晚于域末" = `>= 域末日`。自动截断只用于无终止规则自然展开的额外实例；
   被覆盖移出域外的实例按拒绝处理（优先级高于截断）。
2. 导入预览的基数：个人课表已登记时，基数经 M8 同一解析得到，配置取 `--config`，缺省读注册表 `settings.exam_config`；
   两者都没有 → 只打印课程网格、不打印分钟（不用常数，不从 cap 反推）。
3. 课程事件合并条件：节间隙为 `[上一节.end, 下一节.start)`；与某个 `free_segments` 有**正长度交集**才算"间隙里有空闲时段"，端点相接不算；
   用当天完整的 M18 结果判断（`--classes-only` 时也一样）；分段之后再确定 UID 身份组。
4. ics 类型：`EXDATE`、`RECURRENCE-ID` 与实例身份在原时间域中比较（值与类型都相同才算同一实例）；起止倒置、非法类型组合、无法解析的 `TZID` → 违约；
   不截秒、不猜时区。覆盖事件的 `DTSTART` 类型须与主事件一致；主事件在 §4 第 3 步被剔除时，它的覆盖事件一并进 `notes`（不当作孤立覆盖）。
5. `pyproject.toml` 加 `icalendar>=7,<8`、`python-dateutil>=2.8,<3`、`tzdata`；本机 `py -3.12 -m pip install` 这三个包。
6. 测试：规格 §8 中 ics、export 两部分，外加 sol 225 §二表格每一行与 sol 226 的 N3、N5 例子。
