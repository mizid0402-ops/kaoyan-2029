## 没有把握的地方

1. “完整知识树”是否应把不带编号的 `p` 说明段落单独作为叶节点，任务书没有给出唯一粒度定义。本轮选择保留，因为这些段落确实出现在 archive 正文，删除会丢失主源内容；若项目只要标题/编号条目，可在人工复核时按 `list_item` 与 `detail` 类型裁剪。
2. 科目标题、考查目标组是否应作为可学习知识点而非仅作容器，任务书示例没有明确排除。本轮保留它们，因为它们是 archive 的实际标题节点，并且每条均有来源定位。
3. `sources.locator.offset` 使用 UTF-8 解码后的 Python 字符偏移，不是字节偏移；同时保存 `section` 与 `quote_ref`，因此可以稳定复核，但若下游只接受字节偏移，需要在契约层明确单位。
4. xdf/hep 的许多差异是标点、大小写或教辅重组，不能据此判定 archive 内容错误；本轮没有做“以交叉源纠正主源”的推断。
