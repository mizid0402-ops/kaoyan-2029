# 第 231 轮：M29 正方 PDF 适配器规格细则评审

结论：**FAIL**。按字号区分名称/详情，比第 225 轮的整星期字符串方案更可核对；但白名单与课程分类重叠、续页版式证据未校验，以及缺省周数与 M18 校验顺序冲突仍须修改。当前不能仅凭单个真实样本一致就把“版式不符即报错”交给实现者执行。

证据范围：静态阅读 AGENTS.md、PDF 草案、上级 M29 规格、M18 周次与公开入口规格及第 225 轮报告；补核依赖声明。未联网、未跑测试、未读真实 PDF、个人数据或仓库外文件。探针与一次性原型一致的结果是任务书提供的证据，本轮不能独立验证。下列片段全为构造例子，结果为规则推演，不是运行结果。本轮只新增本报告。

## 一、必须改

以下统一使用 `(page, x, y, font_size, text)`。除明确增加续页标签的例子外，第1页均有：

```text
(1, 100, 100, 12, 星期一)
(1, 100, 200, 12, 星期二)
(1, 100, 300, 12, 星期三)
(1, 100, 400, 12, 星期四)
(1, 100, 500, 12, 星期五)
(1, 100, 600, 12, 星期六)
(1, 100, 700, 12, 星期日)
```

标签严格共线等距，间距100；下面名称/详情均在 y=90，故差值众数为10，星期一锚点90。合成学校档案登记相应节次，学期至少四周。

### P1：白名单与课程条件不是互斥分类，既能丢整门课，也能把页眉拼入名称

涉及 §2 白名单/课程片段与 §3 第4条。

**合成序列 A**：

```text
(1,  80, 90, 9, 乙课程)
(1,  90, 90, 8, (3-4节)1-4周/场地:示例/学分:2)
(1, 200, 90, 9, 甲课程)
(1, 210, 90, 8, (1-2节)1-4周/场地:示例/学分:2)
```

四个片段都符合字号和锚点条件；前两个又符合“第1页 x 小于标签 x”的页眉白名单。草案没有规定二者重叠时如何处理，也未要求课程所在 x 区域必须与页眉区域分离。

**草案允许的结果**：先按白名单过滤，再构造星期课程序列，则整门乙课程被丢弃。剩余甲课程完整，已识别详情中的 `(…节)` 次数为1、课程数为1，每个剩余课程片段都有归属，正常发布只含甲的暂存学期。

**合成序列 B**：

```text
(1,  80, 90, 9, 学期:示例)
(1, 200, 90, 9, 甲课程)
(1, 210, 90, 8, (1-2节)1-4周/场地:示例/学分:2)
```

**草案允许的另一结果**：若先判课程条件，页眉成为第一行名称，与下一行按序连接，得到 `学期:示例甲课程`。一个详情标记对应一门课，全部片段有归属，M18 仅要求名称非空，仍可成功。它不是恶意输入：这是草案主动允许的页眉位置与字号组合。

**应有结果**：不能由分类优先级决定丢课还是污染名称。模板须定义互斥的正文区与页眉/图例区，并把字号、文字形状、位置联合用于白名单；无法唯一分类的片段报版式错误。原始片段中的课程结构标记也应参与覆盖核对，不能先丢弃再只数幸存记录。“所有详情文本”必须明确指原始证据中的哪些片段，而非实现者自行缩成已选正文。

字号12白名单同样应写清是“仅列出的文字及节次编号形状”，还是“任何字号12文字”。后一种会容许整门课程改为12号字后被忽略；即使探针模板不支持这种字体，正确行为也应是报错，不能部分导入。只选一个白名单优先级不足以解决上述两个例子。

### P2：续页有相反版式证据时仍沿用第一页锚点，能静默错收星期

涉及 §2 所有页共用锚点、字号12白名单及 §3 跨页处理。

**合成序列**：第一页除统一标签外，含完整甲课程：

```text
(1, 200, 90, 9, 甲课程)
(1, 210, 90, 8, (1-2节)1-4周/场地:示例/学分:2)
```

第二页的表头重复且整体下移一个星期带：

```text
(2, 100,   0, 12, 星期一)
(2, 100, 100, 12, 星期二)
(2, 100, 200, 12, 星期三)
(2, 100, 300, 12, 星期四)
(2, 100, 400, 12, 星期五)
(2, 100, 500, 12, 星期六)
(2, 100, 600, 12, 星期日)
(2, 200,  90,  9, 乙课程)
(2, 210,  90,  8, (3-4节)1-4周/场地:示例/学分:2)
```

**草案结果**：用于识别的标签来自第1页；第2页星期文字又在字号12白名单内，没有要求检查其坐标与第一页一致。乙的 y=90 精确命中旧星期一锚点，成为星期一课程。两门记录完整、两个详情标记、每个课程片段有归属，均可通过核对。第2页自身标签却明确表明乙属于星期二。

**应有结果**：退出2、不发布暂存，说明续页不符合本模板。无需自动理解这个新布局；必须检查已经可见的反证，而不能白名单放过它。若模板只允许第一页有星期标签，就明确拒绝后页标签；若允许重复标签，则必须逐页核对位置。

仅按 `(page, x)` 拼接和检查前条是否未完整，不能确认页间星期带相同。片段层还应提供模板验证需要的页尺寸/旋转等上下文；跨页续接要求已确认同一坐标模板、同一星期、前记录未结束。无标签续页的模板依据及其验证范围也须写明。此例是正常导出布局变化应被拒绝的问题，不要求支持所有 PDF，也不是恶意构造内部状态。

### P3：缺省周数先取奇偶展开最大值，再保留原文校验，会误拒常见单双周表达式

涉及 §3 第5条、§4 `--weeks` 缺省规则和 M18 §3。

**合成序列**：

```text
(1, 200, 90, 9, 甲课程)
(1, 210, 90, 8, (1-2节)1-16周(单)/场地:示例/学分:2)
```

参数：`--school example_school --label term --week1 2025-09-01`，不传 `--weeks`；示例学校 system=zfsoft，节次合法。

**草案结果**：表达式展开到实际周集合 `1,3,…,15`，最大周15，因此 N=15；随后把原文 `1-16周(单)` 交给 `semester_from_mapping`。M18 要先检查原项上界16≤N，再过滤奇偶，因此违约。这是合法常见表达式，不能同时按草案承诺推导缺省值并成功校验。

**应有结果**：不传 N 时可确定地导入，实际周集合仍为奇数周。最简单是缺省 N 取各原始周次项的最大未过滤上界，本例 N=16，然后复用 M18 先查越界的规则。显式 `--weeks 15` 仍应因原项16越界拒绝；显式16接受。

如果决策者坚持缺省取实际出现最大周15，则需另写“无显式边界时先验证原表达式、再规范化成周集合并构造学期”的公开处理流程，不能绕过显式 N 的越界检查，也不应复制 M18 私有解析器。必须先选择这两种口径之一，不能让实现者猜。

## 二、记录切分、众数与跨页完整判据

在增加以下强前提后，现有记录状态机有合理依据：非正文与正文互斥；片段提取完整；字号9仅属于名称、字号8仅属于详情；每条真实记录有一个节次标记；各页星期带已验证一致。

在这些前提下，名称行后转入详情；再遇名称会结束上一记录。两个详情头串在同一记录里，会使 `(…节)` 次数大于课程数而被拒绝；缺详情或孤立详情也会拒绝。因此本轮没有另造一个“所有前提都成立、所有标记仍被保留，却静默串两门课”的反例。P1/P2 说明草案尚未保证这些前提，不能把结尾正则和计数检查当作独立证明。

`.*` 吞掉的是最终不保留的教师/场地等尾部；在来源分类正确且只有一个节次头的前提下，不必为了保留日程字段建立完整教师字段解析器。学分结尾适合作为本模板的结束线索，不能代替片段归属或续页版式验证。

另一个合成跨页例子：

```text
(1, 200, 90, 9, 甲课程)
(1, 210, 90, 8, (1-2节)1-4周/场地:示例/学分:1)
(2,  20, 90, 8, .5)
```

整条详情的学分是1.5，但第1页末尾已经匹配完整判据，草案会拒绝第2页续接。这会保守误拒，而非静默改变课表字段；“要么正确、要么报错”允许这种限制，本轮列为建议，不因此新增必须改。可明确本模板不支持学分数字跨页拆分；不要仅为接受它取消完整记录后的孤立详情检查。

锚点众数也应在任务书钉住：候选片段来自已互斥分类的哪一组；坐标误差如何聚类；众数并列或为空是否拒绝；怎样从簇求一个确定 d。例如差值10.0、10.2、9.8各出现两次，直接对浮点数取众数无法唯一决定，虽然三者对应的锚点均可能落在0.5容差内。禁止取首个遇到的值或按片段输入顺序打破歧义。单靠 d 的范围检查不会证明全页归属正确。

## 三、与上级规格及 M18 的衔接

除 P3 外，衔接方向一致，可保留：

- `source.adapter=zfsoft_pdf`、源字节摘要、不记录文件名；发布、隔离检查、restage、apply 全部沿用 M29，不新建另一套存储协议。
- `semester_from_mapping` 校验候选本身，再经学校引用校验；与既有学期重叠留给 apply。不能为了打印预览提前拿整份已生效课表拒绝候选。
- M18 接受 `周`、`(单)`/`(双)`，拒绝空展开、重复周次、越界；不为 PDF 适配器放宽业务格式。规范暂存仍由 `semester_to_mapping` 输出升序合并周集合，而不是照抄 PDF 原写法。
- 导入器课程按上级 §3 的键排序，exceptions 为空；随后手工编辑并 restage 的合法例外保留。PDF 不产生停课例外，符合上级边界。
- §4 对上级“第11–12条”的引用包含学校引用验证、临时单学期预览、只加载一次所需档案。摘要中的分钟沿用当前 rules 与 M8 基数；没有登记个人课表就不打印分钟。
- 原 PDF 一次读入字节，摘要和片段提取复用这份输入。解析失败不发布任何部分候选；暂存、临时文件、备份等均沿用隔离检查。

## 四、D6 / D7、不改与任务书细节

**模板常量可以保留。** 字号8/9/12、容差和固定字段前缀是外部格式协议参数，不是写死用户学校、科目、年份或学期。放进有名字的 `zfsoft_rotated_v1` 模板对象，由纯解析函数消费，符合 D6/D7。学校 system 只负责选默认适配器，课程内容及学校档案仍来自登记数据。

新模板若只改变参数，新增模板数据；若改变记录语法，新增适配器并复用候选封装，不在原解析函数堆学校分支。为支持一个已探针模板，无须立即建通用 PDF 框架或外部模板配置语言。

除必须改外，下列可由实现任务书固定，不需单独判 FAIL：

1. 用明确的冻结片段/页面上下文类型，校验 page、有限坐标、字号和文本后再运算；错误带页码、坐标和阶段，但不回显原文或原文件名。原片段身份用于覆盖核对，不靠重新搜索连接后的文本定位。
2. 固定 `cm × tm` 坐标运算约定、页号从1开始、同 x 冲突作用域与坐标容差；众数按上节定义处理，结果不依赖输入枚举顺序。
3. 跨页续接限定相邻页；遇下一条名称或文件结束时，上一记录必须完整。空白页、某星期中间缺页、一个 visitor 文本内有多行时如何处理或拒绝，也须明示，不让解析器无条件跨过它们。
4. 类型标记单独9号行与附在名称末尾按同一规则；只去一个末尾标记、保留名称内部空格。不从学分尾部推导记录身份。
5. `pypdf>=6,<7` 已在依赖声明里，不需要再加第二个 PDF 库；片段接口变化的依赖升级要重核模板夹具。片段层负责读/提取，纯解析层不持有路径、git 或发布逻辑。
6. 实现验收加入 P1 两种分类重叠、P2 续页反证、P3 缺省单双周三组合成用例；真实文件仅由决策者本机比较，不写进测试、报告或 fixtures。

用户的“两条都做、ics 优先、PDF 备用”、暂存后确认生效与个人数据隔离没有被本草案改掉。先收窄并核验模板可以接受；一次性原型逐门一致证明该样本有可行性，不证明白名单和分页变化都能失败关闭。

修正 P1–P3 后，剩余内容可钉在实现任务书里；本轮不要求重选上级 apply/restage 流程，也不评审正在实现的代码。

## 五、安全登记

本轮无新增安全项。导出布局变化、页眉分类重叠、正常单双周表达式属于日常数据处理问题，按必须改处理。恶意超大/复杂 PDF、恶意链接、并发替换及内部暂存篡改沿用既有登记范围，不为本模板另加返工要求。
