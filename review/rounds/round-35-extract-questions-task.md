# 任务：从 HTML 题面抽取题目正文（供 408 讲课 PPT 引用）

## 背景：一个已经查清的事实链

408 讲课 PPT 需要**引用原题**来支撑公信力。此前的脚手架只放题号与页码，**没有题干**，
用户实测后反馈"用作展示公信度的原题没有呈现上来"。

**已实测查清的事实：**

| 事实 | 证据 |
|---|---|
| 项目里的 408 真题 PDF（2022–2025 全部 paper 与 solutions）**文本层字符数 = 0** | `pypdf` 逐页 `extract_text()` 全为空——**它们是图片型扫描件** |
| **题目正文与选项在 `quiz_pages/*.html` 里，是可读文本** | 实测 `cs408_quiz_2024.html` 里能读到完整题干与 A/B/C/D 四个选项 |
| 索引的答案、知识点映射**都是从 HTML 建的**；PDF 只贡献"卷面页码"与"字节哈希" | `tools/build_408_index_v2.py` 的注释与代码 |

**所以：抽题必须从 HTML 抽，读 PDF 是错的。** 前一个脚本
（`tools/extract_408_question_text.py`）读的是 PDF，**抽出 0 条是必然结果**。

## 你要做的

### 1. 重写抽取脚本：从 `quiz_pages/*.html` 抽题

输入：`data/raw_materials/cs408/quiz_pages/cs408_quiz_{2023,2024,2025,2026}.html`

**已实测的坑（务必先看）**：

- **HTML 渲染后没有"行首题号"结构**。实测行首数字只有 4–21 个，而每年有 47 道题。
  **用 `(?m)^\s*\d+[.、．]` 会漏掉绝大多数题。**
- 题面实际形态（实测样例，结构描述）：
  `…题干文字…（）。 链表 \n \n \n A. \n 选项一 \n \n B. \n 选项二 \n \n C. \n … \n D. \n 选项四 查看答案与解析`
  即 **选项标记 `A.` / `B.` / `C.` / `D.` 是可靠锚点**，题干在其之前。
- **不要假设题号是行首**，也不要假设题干与选项在同一行。

**建议做法**：以 `A.`/`B.`/`C.`/`D.` 选项块为锚点切分，往上归并题干；
再用 `question_index.csv` 的题号与顺序**对齐校验**（每年应为 40 道单选 + 7 道综合）。
**把你的实际切分规则完整写进报告。**

### 2. 输出

**新建目录** `review/408知识点树与真题/questions/`，每题一个文件 `{question_id}.txt`，
外加 `questions_index.json`（每题一条记录）。

**每题记录必须含**：

| 字段 | 说明 |
|---|---|
| `question_id` | 如 `cs408-2024-07` |
| `exam_year` / `number` / `question_type` / `marks` | 取自 `question_index.csv` |
| `stem` | **题干**（单项选择去掉四个选项后的部分）|
| `options` | 四个选项的文本（**仅单项选择题**；综合题没有选项，留空）|
| `answer` | 取自 `question_index.csv` 的 `answer`（不要自己推答案）|
| `source_html` | 来源 HTML 文件名 |
| `source_html_sha256` | **现算** |
| `extraction_method` | 你实际用的方法（便于复核）|
| `confidence` | `high` / `medium` / `low`——**切分不确定的必须标低，不要假装确定** |

### 3. 覆盖率与失败清单（必须给）

- 每年抽出多少题 / 应有多少题（应为 47：40 单选 + 7 综合）
- **抽不出的题号清单**及原因
- **切分可疑的题号清单**（如题干里混进了选项、选项数不等于 4）

**抽不出就如实说抽不出，不要用模型知识补写题目。**
**这是本任务最重要的一条纪律**：你**只做抽取**，不做任何内容生成或"补全"。

### 4. 与知识树的关联（供 PPT 用）

按 `kp_to_questions.csv` 生成一张 **`deck_question_map.json`**：
每个讲解单元（`scope=section` 的 116 个节点）→ 它名下所有题目的
`question_id` / 年份 / 题号 / 分值 / 卷面页 / **`stem` 的首 120 字**（供作者取用）。

**注意**：`deck/*.md` 里的"真题定位"表**已经修好了 join**（题目向上归属到所属 section），
**不要改 `deck/*.md`**，只生成这张映射表。
