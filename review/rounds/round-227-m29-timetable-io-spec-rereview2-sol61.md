## 二、必须改

### G1：Git 查询异常不能归入“确认没有 Git 工作树”

位置：§1 状态判定第 3 条“其他情况 → 状态 B”。

**具体设置与输入**：工作区确实位于一个有效 Git 工作树，目标 `exports/demo.ics` 在该树内且没有忽略。运行正常导出命令；这次 Git 查询因普通磁盘读取/权限问题无法读取仓库元数据，`git -C <Workspace.root> rev-parse --is-inside-work-tree` 返回非零，例如 128。Git 可执行文件存在，所以没有进入状态 C。

**草案给出的结果**：不符合“退出 0 且 true”，一律进入状态 B；随后允许写入未隔离的仓库内目标。这里没有攻击者、链接构造或两行之间的竞态，只需要一次普通读取失败。

**应有结果**：查询失败属于“无法确认隔离”，退出 2，不写暂存、备份、导出或临时文件。状态 B 只能表示**已经确认不在工作树内**，不能用所有非成功结果推导这个事实。

同样，状态 A 后的 `rev-parse --show-toplevel` 需要检查成功及有效输出；根查询失败、空输出、进程启动的其他 OSError，也不能继续按一个猜测的根判断目标在树外。

建议把三态写为：A 已确认所属工作树；B 已确认无所属工作树；C Git 不可用或任何查询结果无法确认。B 的确认方式可在实现任务书指定，但不得匹配错误消息文字，也不得仅因退出码非零就返回 B。若无法可靠区分，保守拒绝即可；解压副本允许写入的选择仍可保留，只需先确认其非工作树状态。

**严重度裁定**：必须改。它使普通失败路径绕过用户明确选择的个人数据隔离，并违反“找到但无效/无法读取不能当不存在”的既有原则。不是只需登记的恶意泄漏假设，也不是可以交给实现者自行选择的错误处理策略。

## 四、M18 接缝一致性

本版公开入口划分与现有行为可以一致：

- `timetable_from_mapping` 承接现有文件内解析及 `_validate_semesters` 的规则，整表范围不再含糊。
- `semester_from_mapping` 只验证单学期；`validate_semester_references` 无需人为造 rules，适用于只登记学校的导入。
- `build_calendar` 接受已校验 Timetable，只负责引用核对与构造；sources 缺省为空适用于纯内存候选。
- 正式 `timetable_for_workspace` 仍把实际读取的课表/学校原始字节摘要传进去，不能把纯构造默认空 sources 当成正式加载结果。
- 所有公开类型/函数从包入口导出，M29 不依赖 M18 私有实现；日期和周集合序列化后可按现有 M18 形状往返。

当前实现区分：未登记学校或 ID 不符为 `semesters[i].school`，缺档案经 Workspace 报注册键，课程节次缺失为 `semesters[i].courses[j].periods`；sources 键是工作区根相对 POSIX 路径，摘要来自解析所用字节。本版明确要求这些不变，约束正确。未来实现验收仍需证明，不能把规格通过写成已实现一致。

## 五、可在实现任务书钉住的细节 / 建议改

这些不额外判 FAIL；采用下列明确口径即可，不需新增业务模块。

1. **半开域比较和覆盖来源**：统一使用 `start <= local_date < end_exclusive`，域末日判断写成 `>= end_exclusive`，避免“晚于域末”被实现为严格大于。自动截断仅用于无终止规则自然展开的额外实例；被覆盖主动移出域外的实例按既有拒绝案例处理。任务书注明这一优先级，避免按主规则来源把移动覆盖也截掉。
2. **来源记录及错误路径**：定义 LoadedSchool 的公开字段（profile、来源路径/摘要等）、sources 的只读及复制约定；正式加载复用当前按学期定位的错误上下文。若多处输入同时无效，也保留原先的错误检查顺序，不要因先加载全部学校而先报后一学期的错误。用固定 `1f2df32` 的现有 M18 源码作为对照，不用 HEAD；单次读取和 sources 也参加对照。
3. **导入预览的基数来源**：§4.12 在已有个人课表时打印分钟，需要 `day(d, base_minutes)` 的基数；rules 本身不能提供 M8 配置基数。明确从已登记 exam_config 读取，或给导入入口显式 config 覆盖；配置缺失时是明确拒绝还是只打印课程网格，任务书选择一种。不能用任意常数或从 cap 反推基数。
4. **serializer 的完整形状**：rules 中整数分钟转回严格 HH:MM；`daily_cap_minutes is None` 时省略可选字段，不写 null；例外日期为 ISO 字符串，类型和顺序保持。现有 schema 与往返等价要求已给出方向，任务书只需固定这些表示。
5. **合并条件精确定义**：节间隙按 `[上一节.end, 下一节.start)`，是否存在 free_segment 用正长度交集判断，端点接触不算盖住。计算使用当天完整 M18 结果，不因 classes-only 就跳过 free_segments 检查。按该条件分段后再确定 UID 身份组，保证过滤选项不改变课程 UID。
6. **restage 和变更摘要**：读取/验证整个暂存头、notes 及 semester，只有旧文件名摘要不要求匹配；同哈希返回原文件。比较当前生效学期时也显示例外增删/变化，防止课程差异为零掩盖调休修改。没有生效课表时按新增摘要处理，不为了显示差异强行要求 state.timetable 已登记。
7. **ICS 类型与时长**：界定 UTC/TZID 的结束、EXDATE、RECURRENCE-ID 在原时间域中的身份比较；实际时间转换仍按本版顺序。非法类型组合、起止倒置、无法确定的 TZID 应契约错误，不截秒、不猜时区。覆盖的 DTSTART 类型、继承时长和主事件被剔除后的覆盖处理在任务书中固定，避免分别实现成忽略或孤立覆盖。
8. **命令错误与验收范围**：参数用法错误 3、契约/I/O/隔离失败 2、成功 0；已有发布目标的相同/不同字节按本版规则处理。只增加任务书点名的合成例与固定基线对照，不新增真实个人数据夹具或全量测试要求。
