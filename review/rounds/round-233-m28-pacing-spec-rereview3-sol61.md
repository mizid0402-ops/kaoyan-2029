## 四、建议改／实现任务书钉住的细节

1. **恢复入口只校验保存证据，不校验当前周期设置。** §3 的旧报告拒绝规则被 §6.2
   明确限定为新提交；任务书应避免通用加载函数在分流前先执行当前 cadence/start 校验。
   例如 start 改为 2025-02-01 后，上述 D 不再属于当前周期，既有意图仍须进入恢复表。
   输入包找不到时，§6 已明确违约；不要求增加脱离输入包的新恢复命令。
   对定位 D 所用的保存输入包，应复用一次读取对象，校验形状、kind 和原包规范哈希，
   区分原包完整性核对与“按当前状态重新生成后比较”的新鲜度检查。

2. **将意图字段间的一致性写成明确校验表。** base_revision 是非负精确整数，
   target_revision 等于它加一；b0 是非负精确整数，所有整数排除布尔。
   外层 actor/input_hash 应等于保存 proposal 的同名字段，route.revision 等于 target_revision，
   route.stage1_input_hash 等于意图 input_hash，report_hash 与所绑定保存报告一致。
   两个摘要分别由实际保存的 proposal/route 映射生成，日期采用规范 ISO 映射；
   route 经公开解析接口检查结构，不拿当前设置重新执行业务护栏。
   这些关系来自 §6.1/§7 的既定生成过程，不是新增自由裁定。

3. **manifest 快照查询需新增或扩展公开端口。** route_store.py 的 current()、
   load_revision()、provenance() 各自调用 _read_manifest()；read_state_sources()
   只返回当前路线和来源哈希，不能据其判断历史目标修订的 provenance。
   任务书需明确一个公开读结果同时提供当前修订、目标项来源与已核验的目标路线，
   共用同一次 manifest 读取；复用现有原始字节哈希、revision、route_id 校验规则。
   “按 load_revision 规则核对”指校验语义，不是要求串行调用三个会重读的旧方法。
   写端口持锁后重新读取 manifest 进行下一修订检查仍须保留；§6.1 的一次快照约束针对恢复查询，
   不应被解释为删除写入时的存储检查。M28 不得 import 存储私有方法。

4. **明确两类 SHA-256，保留原始版本校验。** manifest.sha256 是实际 YAML 原始字节摘要，
   意图 route_sha256 是 route_plan_to_mapping 的规范 JSON 摘要，二者不能直接比较。
   先按存储规则验证目标文件，再由解析对象映射计算规范摘要并与 Q 比较。
   proposal_sha256 比较也应使用规范映射，不能因为注释、缩进或键顺序变化判为另一方案。

5. **恢复摘要与 dry-run 文案全部取确认过的内容。** 本次方案不同也不能替换意图中的
   actor、input_hash 或候选 route；待恢复分支可同样提示“本次文件未被采用”。
   dry-run 第一、三行没有将要发布的路线，应显示“不发布”，第二行显示“将恢复提交”，
   不使用正式成功句“已完成”。若当前已有更高修订，第一行摘要应表述为历史应用，
   避免暗示旧方案仍是当前生效路线。退出码沿恢复表，不另选一套 dry-run 码。

6. **列清跨端口同步与摘要来源。** 同步 M0 的解析、require/write_target/指纹行为，
   M11 路线 v3 与映射，M8 基数和 base 来源，M19 条件字段、完成事件可选 study_minutes，
   route_plan.md/availability.md 的来源说明；不要修改 M18 的计算协议。
   如恢复要展示旧配额与 evidence 实值，使用保存输入包中的旧路线和 report；
   不为展示摘要读取当前设置或重建候选。当前路线变化不得改变“实际应用如下”的内容。

## 五、不改

  新提交仍须按当次护栏通过，恢复本身不写冻结/恢复事件。

  不修改已落盘计划和记录；路线历史参考值可能重算。此结果已明文给定，不重新裁定为禁止恢复。
- 保留按需 v2/v3、阶段基数可独立生效、四项联合旧基线与本地注册表夹具约束。
  §2 的“未登记即不启用”按 §9 理解为未启用周期复盘，不抹掉手工路线基数的明确效果。
- 保留 M18 固定提交接口：day/minutes_for 接收逐日 base_minutes，cap 缺省取传入值，
  学期外返回 None；跨阶段报告逐日调用 M8，不能用固定基数 minutes_between 套全周期。
  M26 回落仍报 config，由 M8 按 base_source 映射成 base；不把新来源塞入 M18/M26。
