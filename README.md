# 考研学习 AI 系统 · kaoyan-2029

**把学习计划、复习预算和真实反馈放在同一套本地工作流中。**

Python 3.12 · 本机单用户 · 文件存储 · 按端口替换模块

面向数学一、英语一和 408 的个人备考工具。AI 负责读取资料、准备提案和整理学习反馈，
程序负责校验与保存，网页用于查看安排和操作已开放的本地功能。

### 一次日常学习怎样进行

1. **确定预算**：从本地配置、课表与当天调整得到可用时间。
2. **先排复习**：在分科预算内选择到期项，放不下的明确保留为积压。
3. **准备新课**：AI 使用自己的合法本地资料准备学习内容，经现有端口校验保存。
   每日教学正文属于本地开发版能力。
4. **记录实际情况**：真实作答和学习反馈用于后续安排；规划讨论不冒充学习成果。
5. **周期复盘**：查看覆盖、负担和薄弱点，再确认是否采用调整方案。

框架本身不会自动调用付费模型。定时生成由使用者另行配置 AI 任务；
定时任务存在不代表每次都能成功完成资料读取和内容发布。

## 开始使用

### 1. 获取公开代码

```powershell
git clone https://github.com/mizid0402-ops/kaoyan-2029.git
cd kaoyan-2029
```

需要 Python 3.12。当前代码按源码目录运行；依赖以
[`pyproject.toml`](pyproject.toml) 为准，可在自己的 Python 环境中安装：

```powershell
py -3.12 -m pip install "beautifulsoup4>=4.13,<5" "datasette==0.65.4" "fsrs>=6,<7" `
    "icalendar>=7,<8" "pypdf>=6,<7" "plotly>=6,<7" "python-dateutil>=2.8,<3" `
    "PyYAML>=6,<7" "requests>=2.32,<3" "sqlite-utils>=4.2,<5" tzdata
```

当前尚未配置完整的安装包发现规则，不能把 `pip install .` 当作已验证的安装入口。

### 2. 启动框架示例

```powershell
py -3.12 -m ky web --port 8730 --no-open
```

访问终端显示的本机地址，可以查看今天、复习队列、路线与复盘、图表四个页面。
默认注册表使用`examples/demo/config.yaml`中的合成科目和空学习状态，
不会把示例当作已经发生的学习。没有路线或图表时显示真实空状态。
若端口被占用，可更换`--port`。

服务绑定`127.0.0.1`，局域网与多人共享访问不在当前范围内。

也可以用合成数据单独查看预算计算：

```powershell
py -3.12 -m ky preflight --config tests/fixtures/config/config-minimal.yaml `
    --items tests/fixtures/reviews/reviews-overloaded.yaml --date 2026-09-12
```

这里的日期与数据属于测试示例，不是使用者的个人学习记录。
该命令只读计算，不创建真实学习完成事件。

### 3. 配置自己的本地工作区

数据位置与科目登记在 [`kaoyan.workspace.yaml`](kaoyan.workspace.yaml)。
个人考试配置、课表、学习记录与状态放在被 Git 忽略的本地目录，
通过 `kaoyan.workspace.local.yaml` 补充登记，格式见
[`contracts/workspace.md`](contracts/workspace.md)。

默认注册表没有登记真实知识树和真题索引；词库、权重与来源台账的待配置位置位于
被忽略的`local-inputs/`。这些能力需用户准备有权使用、符合契约的数据后启用。
“示例网页可运行”不等于已经附带完整考研资料或个人学习计划。

## 限制与声明

- 当前服务定位是个人、本机、单用户；公开源码不等于已支持互联网部署或共享写入。
- 知识树的历史提取结果不等于人工金标；数学一与英语一仍有来源复核边界。
- 复习参数和任务量需要真实记录校准；测试通过不证明教学效果或备考收益。
- 政治专属图表尚未实现；Study Workspace 互通适配器是无排期的可选预留。
