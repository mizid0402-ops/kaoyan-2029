## 威胁边界与核对证据

1. **日常正常使用**：手写计划日期和分钟类型、台账编码与重复键属于 R3 的普通健壮性修复，
   不能因本报告列“安全”而延期。路线写入中断留下锁或未登记版本（S5）有明确报错及人工确认后的
   恢复步骤；这是操作限制，若出现无法按该步骤恢复的实例，应作为普通缺陷处理。注册表不可用时
   `day-plan record` 仍记录但不锁存（S10）是 `contracts/freeze.md:38-43` 写明的例外，CLI 给出
   警告；恢复该路径前应先修复注册表。个人运行也可能遇到此条件，不能误称其需要攻击者。
2. **恶意输入或内部手改**：S1 的 `actor` 只是提案声明，不是身份认证；S2 需要无注册表时特意
   把 staging 文件交给 `--plan`；S8 的越界 manifest、S17 的错位事件需要手改内部状态文件。
   S18 需要手工把 `materials.raw_root` 做成指向工作区外的 junction；恢复入口直接使用
   `workspace.raw_root`，而注册表 `_registered_path` 只做字面路径校验，不做解析后包含检查。
   S7、S11–S13 已分别对路线 manifest、staging 真实路径、硬链接写穿、无效注册表做了局部防护。
3. **精确并发交错**：S3（输入包检查后变化）、S4（路线回滚身份核对后变化）、S8（“只写一次”
   两个写者同时发布）、S9（冻结事件同序号不同文件名）、S16（两次读取之间替换）、S19（复习队列
   分片用 `os.replace` 发布，另一写者恰在同一窗口发布同名分片，或失败清理删到别人的文件）都需要另一写者
   插入特定窗口。S19 在第 169 轮拆分时发现，固定基线 `24371ee` 即如此，不是拆分引入。第 130 轮的默认 `--store` 注册表双读窗口已由同一 `Workspace` 对象消除，列为
   S15 已防护；这与仍存在的 S16 日计划/队列双读窗口不同。
4. **网页暴露 S14**：`ky/projection/serve.py` 默认 `host="127.0.0.1"`，传给 Datasette 的参数
   含 `--immutable`。独立定向运行 `tests.test_projection_service.ProjectionServiceTest` 的默认
   immutable、带 `write: true` 的 HTTP 写入、输出刷新三条，**3/3 通过**：canned write 返回
   HTTP 403，投影 meta 未变。`--host` 仍能显式选非本机地址，入口没有身份认证；“immutable”只
   限制数据库写入，不限制别人读取投影。未经审查的插件、反向代理或部署配置不在这三条证据范围内。

第 130 轮默认存储注册表只读一次的定向用例另有 **1/1 通过**。第 153 轮 D7/D8 通过现行代码

## 开源前最小优先集合

若只公开代码，仍维持单用户本机运行，先把 **S1 的权限边界、S10 的注册表例外、S14 的本机
监听默认值**写进对外操作说明，并保持现有防护和测试。仅公开源码本身不等于已允许多人同时写
同一工作区或从网络访问投影。

若准备允许他人访问或共同运行同一工作区，最小代码修复顺序是：

1. **先界定访问与执行权限（S1、S14）**：非本机监听须显式授权或置于有访问控制的代理之后；
   规划者生成的 `actor` 不可代替操作者身份。验证未授权请求不可读取投影，且远程请求不能触发
   submit。继续用 HTTP 写入反例确认投影保持 immutable。
2. **再保证记录不可覆盖、路径留在工作区内（S8、S18、S19）**：完成事件、月结、复习队列分片与 manifest
   采用原子不覆盖发布（S19 照 `route_store._write_version` 改 `os.link`，失败清理只删本次发布的文件）；
   日计划 manifest 闭合解析并限制固定版本路径。原料恢复先检查解析后的 raw_root 仍在工作区内，
   再检查目标仍在 raw_root 内。用两个写者同日提交、伪造 manifest 路径和外指 junction 的反例
   验证；不得删除现有路线/冻结记录的防护。
3. **只有支持共享写入时再闭合事务窗口（S3、S9、S16）**：输入包校验到提交、冻结序号分配到发布、
   队列预检到推进需要一致的版本/锁或可审计重试协议；S4 的回滚窗口一并评估。单进程个人使用
   不因这些并发窗口新增当前阶段的返工包。

S17 属内部文件手改后的完整性；若将状态目录交给同步工具或允许多人手工维护，应在月结入口加入
路径与日期核对。S6 需在安装说明中声明存储文件系统必须支持硬链接发布。以上是**优先级建议**，
没有对任何未实现修法宣称已验证。
