# 模块地图（拼图总图）

> 决议 D7（用户 2026-09-25）：**可维护性与可读性优先**。项目是一幅拼图——每个模块是一块，
> 块与块之间只通过**端口**（`contracts/*.md` 里的规格）咬合；任何一块都能单独替换，新组件按同样的形状拼上去。
>
> 本文件是活文档：**每个工作包完成时更新对应的行**。编号沿用 `docs/模块拆分与架构审查.md` §3。
> 最后更新：2026-10-08（登记 M16 第二版三个只读页与 M33 `load_queue_view`；此前 2026-10-02 登记 M16 首版与 M33）。

## 1. 怎么读这张图

- **端口**：块与块咬合的边。只有写成 `contracts/<端口>.md` 并配了 `tests/contract/test_<端口>*.py` 的，才算"咬合面已定型"。
- **可替换性**：A = 端口已定型，替换者照规格实现并跑通契约测试即可；B = 端口部分定型，替换要读代码；C = 端口未定义。
- **加一块新组件**：写规格 → 实现 → 契约测试 → 在本文件登记一行 → 在工作区注册表登记它读写的文件。不把新功能塞进已有块里。
