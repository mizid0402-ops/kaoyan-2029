# 公开发布说明

核对日期：2026-10-16。适用仓库：`mizid0402-ops/kaoyan-2029`。

## 发布内容

本仓库提供可运行的本机学习框架。README介绍仓库实际提供的能力，
接口与数据格式以`contracts/`为准，启动方式见首页的合成示例。

## 公开与本地的范围

公开保留程序、端口契约、通用工具、合成测试、合成启动配置和必要运行说明。
公开版不再附带`data/`实际数据集、`review/`审查过程、根目录交接文档、
AGENTS内部执行规则、阶段与历史开发文档、`tools/dispatch/`开发派发配置，
以及`tools/archive/`、`tools/migrations/`中的一次性历史脚本。
仅为这些历史脚本服务的两份过程测试也不再公开，核心接口测试保留。

原来拟保留的真题元信息、数值权重和来源台账也留在本地；这是按“只发布框架”的范围决定，
不意味着这些元数据已经被认定侵权。大纲原文、来源摘录、词库撤下同样不构成法律定性。
来源定位测试改用合成句子，保留相应匹配情形的验证。

旧契约或源码注释可能引用本地历史决议编号及原数据路径；它们只是技术追溯信息，
不代表开发过程文件或真实资料仍随公开仓库分发。

## 对使用和验证的影响

默认公开注册表使用`examples/demo/config.yaml`，登记一个合成科目和空学习状态，
支持直接启动本机网页、查看四个页面；没有真实路线、复习或图表时显示空状态。
知识树与词库是可替换的本地输入，未随公开代码提供时，相关登记路径可以不存在。
使用者需自行准备有权使用、满足契约的数据；不能把缺失输入解释成空学习状态或静默跳过错误。

源码保留既有端口，不把真实资料伪装成空壳。合成数据示例可独立展示预算计算；
依赖真实资料的命令和历史数据测试，需要在本机补齐对应输入后再运行。
本轮验证公开版的启动、四页HTTP读取、合成预算命令、来源定位及必要的定向检查，
不扩大为全量测试。示例可启动不代表已经为使用者准备好完整真实学习数据。
