### 2.3 真题与标准答案的真实状态

**核心结论：408 的官方真题与官方参考答案是存在的，且是合法出版物的一部分——它们印在官方大纲的附录里。**

**（1）官方确实发布过真题原文（经官方扫描页直接目视核实）**

官方 2022 版目录扫描图（<https://yankao.neea.edu.cn/res/Home/2111/211154959.jpg>）明确列出附录含：

- 2020 年 408 试题 + **参考答案**
- 2021 年 408 试题 + **参考答案**

2026 版的对应事实经图书馆编目提要核实：

> "本书介绍了 2026 年全国硕士研究生招生考试计算机学科专业基础科目的考试性质、考查目标、考试形式和试卷结构、考查内容、题型示例。**并附有 2024-2025 年全国硕士研究生招生考试计算机学科专业基础试题及参考答案。**"
> —— <https://chaxuntsg.cdjcc.edu.cn/opac/book/5f13aa45a98ad6ba755eaff3a15e0d5c>

同系列说明（图书发行方页面，标注"每册考试大纲后均附有真题试卷、参考答案"）：
<http://www.tsxcfw.com/bookshow.asp?id=3019852>

**（2）因此，"408 是否有官方标准答案公开"的答案是：有，但形态是纸质书附录，不是官网免费下载。**

- 官方**从未在官网单独提供** 408 标准答案的独立电子文件（已核实：官网只有公告页+扫描图）。
- 官方答案的载体是**纸质大纲附录**（2022 版含 2020/2021；2026 版含 2024/2025）。
- 这是"公开出版物"，与"考试期间的国家秘密"不冲突：**命题期间属秘密，考试结束后由官方正式出版即转为公开出版物**。

**（3）法规依据：命题期属国家秘密**

- 《2026年全国硕士研究生招生工作管理规定》第七条：
  "全国硕士研究生招生考试试题（包括副题）、参考答案、评分参考（指南）等应当按照教育工作国家秘密范围的有关规定严格管理。"
  来源：<https://yjsc.zua.edu.cn/info/1039/4458.htm>；
  同条见 2023 年版：<https://www.gov.cn/zhengce/zhengceku/2022-09/07/content_5708701.htm>
- 教育部办公厅《关于加强2005年研究生招生单位自命试题管理工作的通知》（教学厅〔2004〕19号）第 6 条：
  "招生单位自命试题及答案在开考前属国家秘密。"
  来源：<http://www.moe.gov.cn:8080/jyb_xxgk/gk_gbgg/moe_0/moe_1/moe_446/tnull_5601.html>
- 《国家教育考试考务安全保密工作规定》（教考试〔2004〕2 号）第五十一条：
  "在考试期间，不得向任何媒体提供或者在任何媒体上发表考试试题、答案及评分参考；**考试结束后，不得向任何媒体提供或者在任何媒体上发表考试试题的评分细则**。"
  来源：<https://yjs.cuebu.edu.cn/glzd/zcfg/zsl/8863.htm>

> 关键点：法规禁止的时段是"考试期间"，禁止的对象是"命题/评分细则"。**考试结束后由官方自己出版的真题与参考答案，是公开出版物。**
> 但这条第五十一条同时提示：**评分细则（评分参考）即便考后也不得向媒体发表**——系统尤其不应登记评分细则。

**（4）市面流通版本的性质分类（须分别登记，不可混同）**

| 形态 | 性质 | 权利状态 |
|---|---|---|
| 官方大纲附录真题 + 参考答案 | **官方出版物**（教育部教育考试院编，人教社/高教社出版） | 出版者享有版式权与汇编权利；试题与答案由官方首次公开 |
| 教辅收录版（王道、天勤、各类"408 真题详解"） | 教辅作者/出版社**收录并自行解析** | 受教辅自身著作权保护；其解析非官方答案 |
| 考生回忆版 | 考后凭记忆复述 | 无官方效力、不完整、可能有误；来源不明 |
| 扫描件 / 影印流通 | 对上述某一版本的翻拍复制 | 权利状态最不清白，**应排除** |

市面上还有"408 历年真题官方答案勘误"这类第三方汇总（如知乎专栏 <https://zhuanlan.zhihu.com/p/2002893545204360838>），
这本身反证了**民间流传的"官方答案"常与官方原版有出入**——系统若比对答案，须以纸质官方大纲附录为唯一基准。

### 2.4 系统可合法登记的范围

在"只做结构化、不传播原文"的原则下，逐项判定：

**✅ 可以登记（推荐）**

1. **元信息**：科目代码、年度、版本、出版方、ISBN、出版时间、定价、官方公告 URL、扫描图 URL。
   - 依据：版权不保护事实性书目信息；且这些信息来自官方公开页面。
2. **大纲结构（目录层级）**：Ⅰ 考试性质 / Ⅱ 考查目标 / Ⅲ 考试形式和试卷结构 / Ⅳ 考查内容（四门课及其子章节）/ Ⅴ 题型示例 / 附录。
   - 依据：官方目录扫描图为官方公开发布；**目录标题属事实性/结构性信息，登记时标注来源 URL 即可**。
   - 建议：只登记到**章节标题层级**，不要抄录正文段落。
3. **试卷结构与分值**：150 分 /180 分钟 / 各科分值 / 题型分布。
   - 依据：事实性数据。
4. **真题的元信息与哈希**：年份、题号、题型、分科目归属、对应知识点（映射到 408 四门课目录）、难度标注、SHA-256、所据版本（哪一年官方大纲）、权利状态、允许用途。
   - 依据：**这是"登记"而非"复制"**：把真题作为"被索引对象"，只保存定位与校验信息。
   - 这正是现有设计里"只登记来源、取得方式、权利状态、允许用途、SHA-256、版本"的合法落点。
5. **链接**：指向官方公告页、官方扫描图、高教社/人教社产品页、图书馆编目页。
   - 依据：链接与引用属合理使用范畴；不下发文件本体。

**⚠️ 有条件可做（须用户自行提供资料，且需限制）**

6. **考点—真题映射矩阵**：仅登记「某年某题 → 考查哪个知识点」的**指向关系**，不登记题干。
7. **结构对齐**：把教辅目录（高教社"大纲解析"目录）与官方大纲目录做映射，标注差异。
   - 限制：须标明教辅目录**不是**官方大纲；不得把教辅解析当作官方答案。

**❌ 不能登记 / 不能做**

8. **不登记真题题干原文**（无论来自官方附录、教辅、回忆版、扫描件）。
   - 理由：逐字复制构成对出版物的复制与再分发，违背"不传播原文"原则。
9. **不登记参考答案原文、不登记评分细则/评分参考**。
   - 理由：评分细则即便考后也受"不得向媒体发表"的约束（教考试〔2004〕2 号第五十一条）；答案原文属出版物内容。
10. **不批量抓取、不再分发、不做题库正文**——与既定设计原则一致，本次侦察进一步确认其必要性。
11. **不登记来源不明/扫描件/回忆版的"答案"**作为权威答案。

## 五、对系统的直接影响

### ✅ 现在就能做（不依赖用户提供任何资料）

1. **科目结构骨架登记**
   - 408：四门课 + 各章节目录（依据官方目录扫描图与官方出版社产品页）
   - 数学一：数学（一）分卷 + 六大板块（高等数学/线性代数/概率论与数理统计——**该三分类本次未在官方页面逐字核实**，须复核）
   - 英语一：题型结构 + 能力项
2. **元信息与来源台账**：为每门课建立「官方大纲版本表」（年度 / 出版方 / ISBN / 官方公告 URL / 扫描图 URL）。
   - 已核实可直接录入的条目见本文 2.1、3.1、4.1 的表格。
3. **法规与权利状态字段**：把「国家秘密（命题期）→ 官方出版（公开）→ 评分细则（不公开）」三段式写入权利状态枚举。
   - 依据：管理规定的第七条；教考试〔2004〕2 号第五十一条。
4. **真题元信息索引骨架**：字段（年份、科目、题号、题型、知识点、SHA-256、所据版本、权利状态、允许用途），**先建表不填正文**。
5. **链接中心**：收录本文所有官方 URL，作为 `source_url` 白名单。
6. **合规校验规则**：入库内容做「原文长度/连续字符」检测，阻止题干、选项、答案原文进入；阻止扫描件/PDF 上传。

### ⏳ 必须等用户提供资料（纸质官方大纲 / 真题）

1. **官方大纲正文核对**：章节层级是否与教辅目录一致；试卷结构分值的准确数字（尤其英语一题型分值、数学一题型分值）。
2. **真题正文的元信息补全**：题号级索引、知识点映射——需要用户手上有官方大纲附录或纸质真题，**由用户人工录入题号与知识点**（系统不接收题干）。
3. **SHA-256 校验**：需要用户提供其自有副本才能计算；系统不得自行下载扫描件。
4. **2023—2026 年度官方大纲的"官方公告 URL"**：官网列表页无这些年度条目；若用户有纸质书版权页，可据版权页补录 ISBN/出版方（如 2026 版 408 与数学已由第三方书目 + 图书馆编目核实）。
5. **数学一/二/三分卷范围的精确边界**：需对照纸质官方大纲「Ⅲ 试卷分类及使用专业」与「Ⅴ 考试内容和考试要求」。

### ❌ 根本不能做

1. **建立真题正文库**（题干、选项、材料原文）——无论来源是官方附录、教辅还是回忆版。
2. **建立答案库/评分细则库**——答案原文属出版物内容；评分细则受"考后也不得向媒体发表"约束。
3. **批量抓取真题 PDF / 图片 / 扫描件**，或对扫描件做 OCR 全文入库。
4. **再分发**任何真题、答案、大纲正文。
5. **把教辅解析冒充官方答案**；**把回忆版冒充官方真题**。
6. **在系统中标注"官方标准答案"而不指明版本与页码**——408 已有第三方"勘误汇总"证明民间"官方答案"常有出入
   （例：<https://zhuanlan.zhihu.com/p/2002893545204360838>，第三方，仅作旁证）。

### 设计原则再确认

本次侦察**支持**既定原则"只做结构化，不传播原文"，并且**必须收窄一处**：
> 原设定里"408 官方从不公开标准答案"这一条**不准确**。事实是：**官方答案印在官方大纲附录中（合法公开出版物）**，
> 但**不以便于抓取的电子形式单独公开**。
> 因此系统的合规边界不是"官方没有答案"，而是"**有合法来源的答案，但系统不复制它**"——
> 系统只能登记"答案存在于哪本书的哪一页"，不能把答案搬进系统。
